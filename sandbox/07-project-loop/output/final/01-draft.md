# Project Draft

## Project Summary

Obora의 일곱 번째 canonical sandbox 프로젝트입니다. 이 프로젝트는 작은 project lifecycle을 시연하기 위해 설계되었습니다. 초안 작성, 리뷰, 검증, 수정의 과정을 거쳐 최종 승인에 이르는 전체 주기를 포함합니다.

이 sandbox는 의도적으로 초기 검증 단계에서 실패하도록 설계되었으며, 리뷰 과정에서 개선 포인트가 식별되고, repair 단계를 통해 최종 검증이 PASS 되도록 구성됩니다.

## Scope

### In Scope
- Canonical sandbox #7 구조 정의
- Project lifecycle 데모 시나리오 구현
- 초안-리뷰-검증-수정-아카이브 파이프라인 실행
- 한글 기반 문서화

### Out of Scope
- 프로덕션 배포
- 외부 시스템 연동
- 다국어 지원 (영어 등)
