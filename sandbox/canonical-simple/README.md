# Canonical Simple Sandbox

> 상태: **new / canonical draft**
>
> 이 폴더는 앞으로의 sandbox 설계 기준을 잡기 위한 가장 작은 표준 sandbox 초안입니다. 기존 sandbox들을 참고하지 않고, 최소 구조부터 다시 설계하는 출발점으로 사용합니다.

## 목적
- 가장 작은 native workflow 기준 정의
- 입력 1개 / 출력 1개 / 성공 기준 1개를 갖는 최소 sandbox 설계
- 앞으로의 sandbox template 기준점 역할

## 아직 없는 것
- workflow
- config
- agents
- runner
- regression test

## 다음 작은 단계
1. 최소 디렉터리 구조 생성
2. 가장 짧은 native workflow 1개 추가
3. 성공 기준과 expected artifact 정의
