# Problem Seeds

## Seed A — 검증 가능한 고난도 정리
서로소인 양의 정수 a, b에 대해 특정 형태의 정수해 존재 여부를 분석하는 정리.
목표는 완전 증명이 아니라 lemma 분해, 반례 점검, proof gap 기록의 품질을 보는 것.

## Seed B — 반례 탐색 중심 문제
주어진 수열/그래프 성질에 대해 보편 명제가 참인지 검토한다.
목표는 반례 생성과 숨은 가정 탐지를 보는 것.

## Seed C — 난제 스타일 open-ended conjecture
작은 케이스에서는 성립해 보이지만 일반 증명은 어려운 명제를 설정한다.
목표는 solved claim이 아니라 bounded stop 시점의 연구 기록 품질을 보는 것.
