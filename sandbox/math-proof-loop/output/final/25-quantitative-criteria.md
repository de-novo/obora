# 정량적 기준 (Quantitative Criteria)

## 개요

본 문서는 연구 루프의 종료 조건, 이슈 분류, 성공 여부 판정을 위한 **측정 가능한 기준**을 정의한다. 모든 기준은 객관적으로 계량 가능하며, 제3자 재검증이 가능하도록 설계되었다.

---

## P0/P1 이슈 분류 기준

### 분류 원칙

이슈 등급은 **연구 루프의 종료(STOP)를 차단하는지 여부**를 기준으로 분류한다.

| 등급 | 정의 | 차단 여부 | 해결 시점 |
|------|------|-----------|-----------|
| **P0** | 종료 조건을 만족하지 못하게 만드는 치명적 결함 | STOP 차단 | 현재 iteration에서 필수 해결 |
| **P1** | 품질 저하를 유발하나 종료를 차단하지 않는 주요 결함 | STOP 허용 | 다음 iteration까지 해결 가능 |

### P0 분류 기준

| 기준 항목 | 측정 방법 | 임계값 | 예시 |
|-----------|-----------|--------|------|
| **핵심 연구 질문 미답변** | Q-001~Q-003 중 답변되지 않은 질문 수 | ≥ 1개 | Q-001, Q-002, Q-003 중 어느 하나도 답변 없음 |
| **PASS/FAIL 판정 불가** | `20-review-report.md`에서 PASS/FAIL 결론 도출 여부 | 도출 불가 | 기준 부재로 결론이 "불확정" 상태 |
| **안전 종료 메커니즘 부재** | 카운터(`no-progress-ceiling`, `repeated-critical-issue-ceiling`)의 동작 규칙 정의 여부 | 미정의 | 언제 리셋되는지, 언제 증가하는지 규칙 없음 |
| **진전 판단 기준 부재** | "실질 개선"의 정량적 정의 존재 여부 | 미정의 | iteration 간 진전 여부 판단 기준 없음 |
| **핵심 가설 미검증** | H-002, H-003의 최종 상태(supported/rejected)가 아닌 수 | ≥ 1개 | "부분 지지" 또는 "검증 보류" 상태 |

### P1 분류 기준

| 기준 항목 | 측정 방법 | 임계값 | 예시 |
|-----------|-----------|--------|------|
| **문서 포맷 불일치** | 최종 문서의 섹션 구조가 표준과 다른 항목 수 | ≥ 1개 | Abstract, Methodology 섹션 누락 |
| **용어 정의 누락** | 문서 내 중복 사용되나 정의되지 않은 핵심 용어 수 | ≥ 1개 | "iteration", "ceiling" 등의 용어 미정의 |
| **참조 링크 깨짐** | 유효하지 않은 내부 참조 링크 수 | ≥ 1개 | 존재하지 않는 파일로의 링크 |
| **수정 이력 추적 불가** | 결정 로그에 이전 iteration 참조가 누락된 항목 수 | ≥ 1개 | Remediation 내역에 원본 이슈 ID 연결 누락 |
| **보조 가설 미검증** | H-001, H-004, H-005 중 최종 상태가 아닌 수 | ≥ 1개 | "보류" 상태인 보조 가설 |

## PASS/FAIL 임계값

### 리뷰 결과 판정

`20-review-report.md`의 리뷰 결과는 다음 기준에 따라 PASS 또는 FAIL로 판정한다.

| 판정 | 조건 | 필수 충족 항목 |
|------|------|----------------|
| **PASS** | 모든 필수 조건 충족 | 1. P0 이슈 = 0개<br>2. 핵심 연구 질문 답변률 ≥ 95%<br>3. 최종 결론 문서 존재 |
| **FAIL** | 어느 하나라도 미충족 | 1. P0 이슈 ≥ 1개<br>2. 핵심 연구 질문 답변률 < 95%<br>3. 최종 결론 문서 누락 |

### 세부 측정 지표

| 지표 | 측정 방법 | PASS 기준 | FAIL 기준 |
|------|-----------|-----------|-----------|
| **P0 이슈 수** | P0 분류 기준에 따라 식별된 이슈 총개수 | = 0 | ≥ 1 |
| **핵심 연구 질문 답변률** | (답변된 Q-001~Q-003 수) / 3 × 100% | ≥ 95% | < 95% |
| **최종 결론 문서 존재** | `22-final-conclusion.md` 파일 존재 여부 | 존재 | 미존재 |
| **아카이브 패키지 완성도** | 필수 문서(abstract, methodology, decision log, conclusion) 존재 수 | 4/4 | < 4/4 |
| **컨텍스트 유지율** | 이전 iteration에서 정의된 핵심 용어가 유지된 비율 | ≥ 90% | < 90% |

### 리뷰 점수화 (선택적)

| 항목 | 가중치 | 점수 범위 | 점수화 방법 |
|------|--------|-----------|-------------|
| P0 이슈 존재 여부 | 40% | 0 또는 40 | 0개 = 40, 1개 이상 = 0 |
| 연구 질문 답변률 | 30% | 0~30 | (답변률 / 100) × 30 |
| 문서 완성도 | 20% | 0~20 | (존재 필수 문서 수 / 4) × 20 |
| 컨텍스트 유지율 | 10% | 0~10 | (유지율 / 100) × 10 |
| **총점** | 100% | 0~100 | 총합 80점 이상 = PASS, 미만 = FAIL |

## Archive-Ready 임계값

### 정의

**Archive-Ready**는 연구 결과를 제3자에게 전달 가능한 완성된 상태를 의미한다.

### 필수 문서 목록

| 문서 | 경로 | 필수 여부 | 존재 여부 확인 방법 |
|------|------|-----------|---------------------|
| Abstract | `output/final/abstract.md` | 필수 | 파일 존재 및 내용 ≥ 500자 |
| Methodology | `output/final/methodology.md` | 필수 | 파일 존재 및 섹션 구조 완비 |
| Decision Log | `output/final/decision-log.md` | 필수 | 파일 존재 및 모든 결정 기록됨 |
| Conclusion | `output/final/22-final-conclusion.md` | 필수 | 파일 존재 및 결론/한계/후속 연구 포함 |
| Quantitative Criteria | `output/final/25-quantitative-criteria.md` | 필수 | 파일 존재 및 모든 기준 정의됨 |
| P0 Analysis | `output/final/24-p0-analysis.md` | 권장 | 파일 존재 |

### Archive-Ready 판정 기준

| 기준 | 측정 방법 | 임계값 |
|------|-----------|--------|
| **필수 문서 존재** | 필수 문서 5개 중 존재하는 수 | = 5 |
| **문서 내용 최소 길이** | 각 문서의 내용 길이(문자 수) | ≥ 500자/문서 |
| **참조 링크 유효성** | 깨진 내부 참조 링크 수 | = 0 |
| **용어 정의 완성도** | 핵심 용어(10개) 중 정의된 수 | ≥ 9 |
| **결정 로그 완결성** | 모든 iteration의 결정이 기록된 비율 | = 100% |

### Archive-Ready 상태 결정

| 상태 | 조건 |
|------|------|
| **READY** | 모든 기준 충족 (위 5개 기준 모두 만족) |
| **NEAR-READY** | 필수 문서 5개 존재, 내용/참조/용어 중 1개 미충족 |
| **NOT-READY** | 필수 문서 1개 이상 누락 |

## Bounded-Stop 임계값

### 정의

**Bounded-Stop**은 안전 종료 조건이 충족되어 루프를 중단하고 유한한 결론을 작성하는 상태를 의미한다.

### 안전 종료 조건 파라미터

| 파라미터 | 기본값 | 정의 |
|----------|--------|------|
| `max iterations` | 5 | 총 최대 허용 iteration 수 |
| `no-progress ceiling` | 3 | 연속으로 실질 개선이 없는 허용 횟수 |
| `repeated critical issue ceiling` | 2 | 동일 핵심 이슈 반복 허용 횟수 |

### 측정 지표

| 지표 | 측정 방법 | 임계값 |
|------|-----------|--------|
| **현재 iteration 수** | 수행된 총 iteration 횟수 | ≥ `max iterations` (5) |
| **실질 개선 없는 연속 iteration 수** | 카운터 `no-progress-counter` | ≥ `no-progress ceiling` (3) |
| **동일 핵심 이슈 반복 횟수** | 카운터 `repeated-critical-issue-counter` | ≥ `repeated critical issue ceiling` (2) |
| **진전 지표 변화량** | iteration 간 미해결 질문 수 감소량 | ≤ 0 (3회 연속) |
| **가설 검증 상태 변화** | iteration 간 "보류" 상태 가설 수 변화량 | ≤ 0 (3회 연속) |

### 실질 개선 판정 기준

"실질 개선"은 다음 **모든** 조건을 만족할 때 인정한다.

| 조건 | 측정 방법 | 임계값 |
|------|-----------|--------|
| **미해결 질문 수 감소** | 이전 iteration 대비 미해결 질문 수 변화량 | ≤ -1 (1개 이상 감소) |
| **가설 검증 진전** | "보류" 상태였던 가설이 "지지/거부"로 상태 변경된 수 | ≥ 1 |
| **P0 이슈 수 감소** | 이전 iteration 대비 P0 이슈 수 변화량 | ≤ -1 (1개 이상 감소) |

### 동일 핵심 이슈 판정 기준

"동일 핵심 이슈"는 다음 **모든** 조건을 만족할 때 동일 이슈로 간주한다.

| 조건 | 설명 |
|------|------|
| 이슈 타입 동일 | 동일한 P0/P1 카테고리 |
| 근본 원인 동일 | 동일한 근본 결함(P0-001~P0-004 중 하나) |
| 해결 방안 무변화 | remediation 방안이 이전과 동일하거나 미미하게 다름 |

### Bounded-Stop 상태 결정

| 상태 | 조건 |
|------|------|
| **TRIGGERED** | 안전 종료 조건 4개 지표 중 **어느 하나** 이상 임계값 도달 |
| **NOT-TRIGGERED** | 모든 안전 종료 조건 지표가 임계값 미만 |

### Bounded Conclusion 작성 조건

Bounded-Stop이 TRIGGERED된 경우, 다음 **모든** 조건 충족 시 bounded conclusion 작성:

| 조건 | 설명 |
|------|------|
| P0 이슈가 0개가 아님 | 수렴 실패 인정 |
| 현재까지 도달한 결론이 문서화됨 | 부분적 결론 기록 |
| 한계와 후속 연구 제안이 포함됨 | 투명성 보장 |
| "안전 종료로 인한 유한 결론"임이 명시됨 | 상태 명시 |

## 기준 적용 순서

```
┌─────────────────────────────────────────────────────────┐
│ 1. iteration 시작 시 카운터 초기화                        │
│    - no-progress-counter = 0                            │
│    - repeated-critical-issue-counter = 0                │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│ 2. 리뷰 결과 판정 (20-review-report.md)                 │
│    - P0 이슈 수 ≥ 1 → FAIL                               │
│    - P0 이슈 수 = 0, 핵심 질문 답변률 ≥ 95% → PASS       │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│ 3. Archive-Ready 판정                                    │
│    - 필수 문서 5개 존재, 내용/참조/용어 기준 충족        │
│    - READY → 아카이브 패키지 생성                        │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│ 4. Bounded-Stop 판정                                      │
│    - 안전 종료 조건 임계값 도달 여부 확인                │
│    - TRIGGERED → bounded conclusion 작성 후 루프 중단   │
│    - NOT-TRIGGERED → 다음 iteration 진행                │
└─────────────────────────────────────────────────────────┘
```

## 기준 간 관계 요약

| 기준 | 상위 기준 | 종속 기준 |
|------|-----------|-----------|
| P0/P1 분류 | PASS/FAIL 판정 | 정량적 기준(P0-001~P0-004) |
| PASS/FAIL | Archive-Ready | 리뷰 점수, P0 이슈 수 |
| Archive-Ready | 최종 산출물 전달 | 필수 문서 완성도 |
| Bounded-Stop | 안전 종료 결정 | iteration 카운터, 진전 지표 |
