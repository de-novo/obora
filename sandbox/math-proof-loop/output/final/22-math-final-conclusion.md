## 2. 증명 완결성 선언

### 2.1 증명 구조

**정리**: ∀n ∈ ℕ, n ≥ 1: ∑_{k=1}^{n} k³ = [n(n+1)/2]²

**증명** (수학적 귀납법):

**1단계: 기저 경우 (Base Case)**
- n = 1일 때:
  - 좌변: ∑_{k=1}^{1} k³ = 1³ = 1
  - 우변: [1·2/2]² = 1² = 1
  - ∴ 좌변 = 우변 ✓

**2단계: 귀납 가정 (Inductive Hypothesis)**
- 임의의 k ≥ 1에 대해 P(k)가 성립한다고 가정:
  $$\sum_{i=1}^{k} i^3 = \left(\frac{k(k+1)}{2}\right)^2$$

**3단계: 귀납 단계 (Inductive Step)**
- P(k+1)을 증명:
  $$\sum_{i=1}^{k+1} i^3 = \left(\frac{(k+1)(k+2)}{2}\right)^2$$

- **좌변 전개**:
  $$\sum_{i=1}^{k+1} i^3 = \sum_{i=1}^{k} i^3 + (k+1)^3$$
  $$= \left(\frac{k(k+1)}{2}\right)^2 + (k+1)^3$$
  $$= \frac{k^2(k+1)^2}{4} + (k+1)^3$$
  $$= \frac{k^4 + 2k^3 + k^2 + 4k^3 + 12k^2 + 12k + 4}{4}$$
  $$= \frac{k^4 + 6k^3 + 13k^2 + 12k + 4}{4}$$

- **우변 전개**:
  $$\left(\frac{(k+1)(k+2)}{2}\right)^2 = \frac{(k+1)^2(k+2)^2}{4}$$
  $$= \frac{(k^2 + 2k + 1)(k^2 + 4k + 4)}{4}$$
  $$= \frac{k^4 + 6k^3 + 13k^2 + 12k + 4}{4}$$

- **결론**: 좌변 = 우변 ✓

**4단계: 귀납법 적용**
- P(1) 참 (기저 경우)
- P(k) → P(k+1) 참 (귀납 단계)
- ∴ ∀n ≥ 1: P(n) 참 ∎
