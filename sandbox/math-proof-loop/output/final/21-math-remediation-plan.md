## 2. P2 Gap Remediation Plans

### 2.1 P2-1: 변수 명명 규칙 혼용

#### 문제 설명

증명 과정에서 $n$, $k$, $i$가 혼용되어 일관성이 떨어짐

**현재 상태**:
- 명제 정의: $n$ 사용
- 귀납 가정: $k$ 사용
- 합의 인덱스: $i$ 사용

#### 개선 방안

**옵션 A: $n$으로 통일**
```
Before: 임의의 양의 정수 k에 대해 P(k)를 가정
After:  임의의 양의 정수 n에 대해 P(n)을 가정
```

**옵션 B: 명확한 역할 구분 (권장)**
```
- n: 일반적인 자연수 (명제 변수)
- k: 귀납 가정의 특정 값
- i: 합의 인덱스

명시적 선언 추가:
"귀납 가정에서 k를 사용하며, 이는 특정 자연수를 나타낸다.
합의 인덱스 i는 1부터 k까지 변화하는 더미 변수이다."
```

#### Remediation Steps

1. [ ] 변수 사용 규칙 문서화
2. [ ] 11-proof-attempt.md에 명시적 선언 추가

### 2.2 P2-2: "직접 계산" 과정 생략

#### 문제 설명

기저 사례와 검증 단계에서 계산 과정이 "직접 계산"으로 생략됨

**현재 상태**:
```
Step 1: LHS = 1³ = 1 (생략)
Step 5: ∑k³ = 225 (생략)
```

#### 개선 방안

**명시적 계산 과정 추가**:

```
Step 1 (기저 사례) 상세:
  LHS = ∑_{k=1}^{1} k³
      = 1³
      = 1 × 1 × 1
      = 1
  
  RHS = [1×(1+1)/2]²
      = [1×2/2]²
      = [2/2]²
      = 1²
      = 1
  
  결론: LHS = RHS = 1 ✓

Step 5 (n=5 검증) 상세:
  LHS = 1³ + 2³ + 3³ + 4³ + 5³
      = 1 + 8 + 27 + 64 + 125
      = 9 + 27 + 64 + 125
      = 36 + 64 + 125
      = 100 + 125
      = 225
  
  RHS = [5×6/2]²
      = [30/2]²
      = 15²
      = 225
  
  결론: LHS = RHS = 225 ✓
```

#### Remediation Steps

1. [ ] Step 1 계산 과정 명시적 추가
2. [ ] Step 5의 n=5 계산 과정 명시적 추가
3. [ ] 선택적: n=10 계산 과정 추가

#### 예상 소요 시간

10분

#### 우선순위

높음 (재현성 향상)

### 2.3 P2-3: $n=0$ 경계 조건 미명시

#### 문제 설명

명제가 $n \geq 1$로 제한되었으나, $n=0$에서도 성립함이 언급되지 않음

**현재 상태**:
- 명제: "모든 양의 정수 $n \geq 1$에 대해"
- 실제: $n=0$에서도 성립

**검증**:
- $n=0$: LHS = $\sum_{k=1}^{0} k^3 = 0$ (empty sum)
- RHS = $\left(\frac{0 \cdot 1}{2}\right)^2 = 0$
- 성립함 ✓

#### 개선 방안

**옵션 A: 명제 확장**
```
Before: 모든 양의 정수 n ≥ 1에 대해
After:  모든 음이 아닌 정수 n ≥ 0에 대해
```

**옵션 B: 주석 추가 (권장)**
```
명제: 모든 양의 정수 n ≥ 1에 대해 P(n)이 성립한다.

비고: n=0에서도 성립함이 확인되나, 
      본 증명의 범위는 n ≥ 1로 한정한다.
      n=0으로의 확장은 자명하다.
```

#### Remediation Steps

1. [ ] 01-math-problem-frame.md에 비고 추가
2. [ ] 11-proof-attempt.md에 n=0 검증 추가 (선택적)
3. [ ] 범위 확장 여부 결정

#### 예상 소요 시간

2분

#### 우선순위

낮음 (완전성 향상, 필수 아님)

| F2 | 자연수에서 덧셈/곱셈에 대한 닫힘성 | Peano Axioms | Closure property |
