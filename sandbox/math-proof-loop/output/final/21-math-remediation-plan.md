## 2. P1 Gap Remediation 계획

### 2.1 GAP-P1-001: 텔레스코핑 항의 발견 방법론

#### 현황
- **유형**: Methodological Gap
- **상태**: 🔶 부분 해결
- **영향**: 텔레스코핑 증명의 투명성 저하

#### Remediation 옵션

**옵션 A: 유일성 증명 추가** (권장)
- **내용**: 부록에 "텔레스코핑 항의 유일성 증명" 추가
- **작업량**: 낮음 (1-2시간)
- **효과**: "임의성" 의심 해소
- **구현 방법**:
  ```
  부록 A.3: 텔레스코핑 항의 유일성
  
  정리: k³ = [g(k)]² - [g(k-1)]²를 만족하는
        2차 이하 다항식 g(k)는 g(k) = k(k+1)/2뿐이다.
  
  증명:
  g(k) = ak² + bk + c로 설정
  [g(k)]² - [g(k-1)]² = k³이 되도록 계수 결정
  ... (전개) ...
  결과: a = 1/2, b = 1/2, c = 0
  따라서 g(k) = k(k+1)/2이 유일한 해 ∎
  ```

**옵션 B: 발견적 접근 서술**
- **내용**: "동기 부여" 섹션 추가
- **작업량**: 중간 (2-3시간)
- **효과**: 교육적 가치 향상
- **구현 방법**:
  ```
  섹션 3.2.1: 텔레스코핑 항의 동기
  
  k³을 연속된 제곱의 차로 표현하려는 시도에서 출발:
  - k³ = [f(k)]² - [f(k-1)]² 형태 가정
  - f(k)가 다항식이라고 가정하면 차수는 2 이하
  - f(k) = ak² + bk + c로 설정 후 계수 비교
  ... (과정 서술) ...
  ```
