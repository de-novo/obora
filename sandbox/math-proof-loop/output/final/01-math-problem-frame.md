# 수학 문제 프레임 — 01-math-problem-frame

---

## 문제 정의

양의 정수 $n$에 대해, 세제곱의 합이 자연수 합의 제곱과 항상 일치하는지를 증명 또는 반증한다. 구체적으로 다음 명제를 검토한다.

$$
P(n): \quad \sum_{k=1}^{n} k^3 = \left(1 + 2 + \cdots + n\right)^2
$$

등가 형태로, 자연수 합 공식 $\displaystyle \sum_{k=1}^{n} k = \frac{n(n+1)}{2}$를 사용하면:

$$
\sum_{k=1}^{n} k^3 = \left(\frac{n(n+1)}{2}\right)^2
$$

을 증명해야 한다.

---

## Conjecture / Target Statement

**Target Statement (T)**:
> 모든 양의 정수 $n \ge 1$에 대해, 세제곱의 합은 자연수 합의 제곱과 같다.

$$
T: \quad \forall n \in \mathbb{Z}^+, \; \sum_{k=1}^{n} k^3 = \left(\frac{n(n+1)}{2}\right)^2
$$

이 명제가 참인지(증명), 거짓인지(반례 존재), 또는 현재 기준으로 증명 불가한지를 판정하는 것이 목표다.

---

## Assumptions

1. **자연수 합 공식은 성립**:
   $$\sum_{k=1}^{n} k = \frac{n(n+1)}{2}, \quad \forall n \in \mathbb{Z}^+$$
   이 공식은 이미 알려진 정리로 가정하며, 본 실험에서 재증명하지 않는다.

2. **산술 연산 법칙은 성립**:
   - 덧셈/곱셈의 교환법칙, 결합법칙
   - 분배법칙
   - 자연수에 대한 닫힘성

3. **수학적 귀납법 사용 가능**:
   자연수에 대한 명제 증명에서 수학적 귀납법을 사용할 수 있다고 가정한다.

4. **대수적 동치 변형 허용**:
   양변에 같은 값을 더하거나 곱하는 등의 동치 변형은 논리적 타당성을 유지한다.

5. **계산 가능성**:
   유한한 $n$에 대해 좌변과 우변을 직접 계산하여 일치 여부를 확인할 수 있다.

---

## Non-Goals

1. **자연수 합 공식의 증명은 제외**:
   $\sum_{k=1}^{n} k = \frac{n(n+1)}{2}$의 증명은 이번 범위 밖이다.

2. **일반화된 멱합 공식 유도 제외**:
   $\sum_{k=1}^{n} k^m$에 대한 일반 공식 유도는 목표가 아니다. 오직 $m=3$인 경우만 다룬다.

3. **다른 수 체계로의 확장 제외**:
   정수, 유리수, 실수, 복소수 등으로의 확장은 고려하지 않는다. 양의 정수 범위에 한정한다.

4. **생성 함수나 조합론적 접근은 선택사항**:
   사용할 수 있지만, 필수가 아니다. 귀납법이나 직접 대수 전개로도 충분하다면 그 방법을 우선한다.

5. **완벽한 최단 증명 제출 제외**:
   "가장 우아한 증명"을 찾는 것이 아니라, 논리적으로 완전한 증명 경로를 구축하는 것이 목표다.

6. **미해결 난제 해결 시도 아님**:
   이 문제는 이미 해결된 정리지만, **증명 탐색 루프의 운영 능력**을 검증하기 위해 사용한다.

## 이번 Iteration의 성공 조건

### 1. 문제 구조화 성공
- [ ] 문제가 conjecture, assumptions, non-goals로 명확히 분리됨
- [ ] target statement가 형식적으로 잘 정의됨
- [ ] 증명 대상과 가정의 경계가 모호하지 않음

### 2. Lemma 후보 생성
- [ ] 적어도 2개 이상의 의미있는 lemma 후보가 식별됨
- [ ] 각 lemma가 target statement의 증명에 어떻게 기여하는지 설명됨
- [ ] lemma 간 의존 관계가 파악됨

### 3. Proof Attempt 수행
- [ ] 최소 1개의 증명 경로가 단계별로 작성됨
- [ ] 각 단계에서 사용하는 가정/정리/lemma가 명시됨
- [ ] 귀납법 사용 시 기저 단계와 귀납 단계가 분리됨

### 4. Counterexample / Consistency Check
- [ ] $n = 1, 2, 3, 4, 5$에 대해 양변 값을 계산하여 일치 확인
- [ ] 반례가 존재할 수 있는 조건을 명시적으로 점검
- [ ] "반례 없음"이 근거와 함께 서술됨

### 5. Proof Gap 명시
- [ ] 증명 시도에서 논리적 비약이나 생략된 단계가 있으면 명시
- [ ] "자명", "쉽게 알 수 있다" 등의 표현 뒤에 실제 근거가 따라옴
- [ ] gap이 해결되지 않은 경우 "unresolved gap"으로 기록

### 6. Review / Remediation
- [ ] self-review에서 최소 1개 이상의 개선점 식별
- [ ] remediation이 단순 재서술이 아니라 구조적 개선을 포함
- [ ] false progress(근거 없는 성공 선언)가 발견되면 수정

### 7. Final Conclusion 명확성
- [ ] 최종 결론이 다음 중 하나로 명시됨:
  - **SOLVED**: 완전한 증명 확보
  - **PARTIALLY SUPPORTED**: 일부 경우 증명, 일부 미해결
  - **UNRESOLVED**: 증명 완료 실패, 공백 존재
  - **REFUTED**: 반례 발견으로 명제 거짓 판명
- [ ] 결론에 대한 근거가 명확히 제시됨

### 8. Archive 품질
- [ ] 탐색 과정이 재현 가능한 형태로 기록됨
- [ ] 다음 iteration에서 활용 가능한 정보가 포함됨
- [ ] "해결 여부"와 무관하게 연구 기록으로서 가치가 있음

## 참고 사항

이 문제는 이미 해결된 정리로, 표준적인 증명 방법은 다음을 포함한다:
- 수학적 귀납법
- 대수적 항등식 전개
- 생성 함수 접근
- 조합론적 해석 (직사각형 분할 등)

그러나 본 실험에서는 **정답을 아는 상태에서 증명을 구성하는 능력**보다는 **모르는 상태에서 탐색하는 과정의 구조화 능력**을 평가한다. 따라서 모델이 스스로 증명 경로를 발견하고, gap을 식별하며, false progress를 수정하는 과정을 관찰한다.
