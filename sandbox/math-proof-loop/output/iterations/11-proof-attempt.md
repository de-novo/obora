# 11. Proof Attempt (증명 시도)

## 개요

본 문제의 명제를 **수학적 귀납법**을 사용하여 증명합니다.

**명제:** 모든 양의 정수 \( n \ge 1 \)에 대해

\[
\sum_{k=1}^{n} k^3 = \left( \frac{n(n+1)}{2} \right)^2
\]

---

## Proof Structure (증명 구조)

1. **Base Case (기본 단계):** \( n = 1 \)일 때 명제가 성립함을 증명
2. **Inductive Hypothesis (귀납 가정):** \( n = m \)일 때 명제가 성립한다고 가정
3. **Inductive Step (귀납 단계):** 귀납 가정을 사용하여 \( n = m+1 \)일 때도 성립함을 증명
4. **Conclusion (결론):** 수학적 귀납법에 따라 모든 양의 정수 \( n \)에 대해 성립

---

## Step 1: Base Case (기본 단계)

**목표:** \( n = 1 \)일 때 명제가 성립함을 확인.

**좌변 (LHS):**

\[
\sum_{k=1}^{1} k^3 = 1^3 = 1
\]

**우변 (RHS):**

\[
\left( \frac{1(1+1)}{2} \right)^2 = \left( \frac{1 \cdot 2}{2} \right)^2 = \left( \frac{2}{2} \right)^2 = 1^2 = 1
\]

**결과:** \( \text{LHS} = \text{RHS} = 1 \)

---

**✓ Gap Check (Base Case):**
- 직접 계산으로 확인하였으며, 추가적인 가정이 없음.
- **현재 Gap:** 없음.

---

## Step 2: Inductive Hypothesis (귀납 가정)

**가정:** \( n = m \) (임의의 양의 정수)일 때 명제가 성립한다.

\[
\sum_{k=1}^{m} k^3 = \left( \frac{m(m+1)}{2} \right)^2 \quad \text{(Inductive Hypothesis)}
\]

---

## Step 3: Inductive Step (귀납 단계)

**목표:** \( n = m+1 \)일 때도 명제가 성립함을 증명.

### 3.1 좌변 (LHS) 전개

\[
\sum_{k=1}^{m+1} k^3 = \sum_{k=1}^{m} k^3 + (m+1)^3
\]

**귀납 가정 대입 (Lemma 6 적용):**

\[
= \left( \frac{m(m+1)}{2} \right)^2 + (m+1)^3
\]

---

**🔶 비약 표시 1:**
- "귀납 가정을 대입한다"는 것은 명제적으로 올바르나, 전개 과정에서 **대수적 오류** 가능성이 있음.
- 다음 단계에서 명시적으로 전개하여 확인 필요.

---

### 3.2 우변 (RHS) 전개

\[
\left( \frac{(m+1)(m+2)}{2} \right)^2 = \frac{(m+1)^2(m+2)^2}{4} \quad \text{(Lemma 4 적용)}
\]

---

**🔶 비약 표시 2:**
- \( (m+2)^2 \)를 전개하지 않고 그대로 둔 상태에서 좌변과 비교하려 함.
- 좌변은 \( (m+1)^3 \) 항을 포함하고 있는데, 우변은 \( (m+1)^2 \)로 시작하므로 **형태가 다름**.
- 양변을 동일한 형태로 전개하여 비교해야 함.

---

### 3.3 좌변 세부 전개

**Lemma 2 (세제곱 전개) 적용:**

\[
(m+1)^3 = m^3 + 3m^2 + 3m + 1
\]

**좌변 재작성:**

\[
\left( \frac{m(m+1)}{2} \right)^2 + (m+1)^3 = \frac{m^2(m+1)^2}{4} + (m^3 + 3m^2 + 3m + 1)
\]

---

### 3.4 분모 통일 (Lemma 5 적용)

두 항을 통합하기 위해 분모를 4로 통일:

\[
= \frac{m^2(m+1)^2 + 4(m^3 + 3m^2 + 3m + 1)}{4}
\]

---

### 3.5 분자 전개

\[
m^2(m+1)^2 = m^2(m^2 + 2m + 1) = m^4 + 2m^3 + m^2
\]

\[
4(m^3 + 3m^2 + 3m + 1) = 4m^3 + 12m^2 + 12m + 4
\]

**분자 합산:**

\[
m^4 + 2m^3 + m^2 + 4m^3 + 12m^2 + 12m + 4 = m^4 + 6m^3 + 13m^2 + 12m + 4
\]

---

**🔶 비약 표시 3:**
- 위 전개 과정에서 계산이 올바른지 검증 필요.
- 특히 \( m^4 + 6m^3 + 13m^2 + 12m + 4 \)가 올바른 분자인지 확인 필요.

---

### 3.6 우변 분자 전개

\[
(m+1)^2(m+2)^2 = (m^2 + 2m + 1)(m^2 + 4m + 4)
\]

**전개:**

\[
\begin{aligned}
&= m^2(m^2 + 4m + 4) + 2m(m^2 + 4m + 4) + 1(m^2 + 4m + 4) \\
&= m^4 + 4m^3 + 4m^2 \\
&\quad + 2m^3 + 8m^2 + 8m \\
&\quad + m^2 + 4m + 4 \\
&= m^4 + 6m^3 + 13m^2 + 12m + 4
\end{aligned}
\]

---

**🔶 비약 표시 4:**
- 위 전개 과정에서 계산이 올바른지 검증 필요.
- 좌변 분자와 우변 분자가 일치하는지 확인 필요.

---

### 3.7 좌변과 우변 비교

**좌변:**

\[
\frac{m^4 + 6m^3 + 13m^2 + 12m + 4}{4}
\]

**우변:**

\[
\frac{(m+1)^2(m+2)^2}{4} = \frac{m^4 + 6m^3 + 13m^2 + 12m + 4}{4}
\]

**결과:** 좌변 = 우변

---

## Step 4: Conclusion (결론)

1. **Base Case:** \( n = 1 \)일 때 명제가 성립함을 확인하였습니다.
2. **Inductive Step:** \( n = m \)일 때 명제가 성립한다고 가정하면, \( n = m+1 \)일 때도 명제가 성립함을 증명하였습니다.
3. **수학적 귀납법**에 따라, 모든 양의 정수 \( n \ge 1 \)에 대해 명제가 성립합니다.

\[
\boxed{\sum_{k=1}^{n} k^3 = \left( \frac{n(n+1)}{2} \right)^2 \quad \forall n \in \mathbb{Z}^+, n \ge 1}
\]
