# Lemma 후보 — 10-lemma-candidates

**생성 일시**: 2026-03-15  
**목적**: $\sum_{k=1}^{n} k^3 = \left(\frac{n(n+1)}{2}\right)^2$ 증명에 필요한 보조 명제 식별

---

## 1. Lemma 후보 목록

### L1: 세제곱 전개 항등식
**명제**: $(k+1)^3 = k^3 + 3k^2 + 3k + 1$

**분류**: 계산적 보조정리 (Computational)  
**난이도**: 낮음  
**의존성**: F1 (분배법칙), F11 (완전제곱 확장)  
**증명 상태**: ✅ 알려진 사실, 증명 불필요

**활용 지점**: 귀납 단계에서 $(k+1)^3$을 전개할 때 사용

---

### L2: 제곱합 공식 (선택적)
**명제**: $\sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}$

**분류**: 관련 정리 (Related Theorem)  
**난이도**: 중간  
**의존성**: F9 (known result)  
**증명 상태**: ✅ 알려진 사실 (F9), 본 증명에서 활용 가능

**활용 지점**: 귀납 단계 대수 전개 시 $k^2$ 항 정리에 사용 가능  
**비고**: 반드시 필요하지는 않음. 직접 전개로 우회 가능

---

### L3: 귀납 단계 핵심 항등식
**명제**: 
$$\left(\frac{k(k+1)}{2}\right)^2 + (k+1)^3 = \left(\frac{(k+1)(k+2)}{2}\right)^2$$

**분류**: 핵심 보조정리 (Critical Lemma)  
**난이도**: 높음  
**의존성**: A1 (자연수 합 공식), F11, F12 (대수 항등식)  
**증명 상태**: ❌ 미증명 — 본 증명의 핵심 과제

**활용 지점**: 귀납 단계에서 귀납 가정과 결론을 연결  
**비고**: 이 항등식이 증명되면 전체 증명 완료

**전개 방향**:
$$\text{LHS} = \frac{k^2(k+1)^2}{4} + (k+1)^3 = \frac{k^2(k+1)^2 + 4(k+1)^3}{4}$$
$$= \frac{(k+1)^2[k^2 + 4(k+1)]}{4} = \frac{(k+1)^2(k^2 + 4k + 4)}{4}$$
$$= \frac{(k+1)^2(k+2)^2}{4} = \left(\frac{(k+1)(k+2)}{2}\right)^2 = \text{RHS}$$

---

### L4: 인수분해 항등식
**명제**: $k^2 + 4k + 4 = (k+2)^2$

**분류**: 계산적 보조정리 (Computational)  
**난이도**: 낮음  
**의존성**: F11 (완전제곱)  
**증명 상태**: ✅ 자명 (완전제곱 공식의 직접 적용)

**활용 지점**: L3 전개 과정에서 사용

---

### L5: 공통 인수 추출
**명제**: $k^2(k+1)^2 + 4(k+1)^3 = (k+1)^2[k^2 + 4(k+1)]$

**분류**: 계산적 보조정리 (Computational)  
**난이도**: 낮음  
**의존성**: F1 (분배법칙)  
**증명 상태**: ✅ 자명 (인수분해)

**활용 지점**: L3 전개 과정에서 사용

---

### L6: 기저 사례 검증
**명제**: $n = 1$일 때, $\sum_{k=1}^{1} k^3 = \left(\frac{1 \cdot 2}{2}\right)^2$

**분류**: 검증 보조정리 (Verification Lemma)  
**난이도**: 낮음  
**의존성**: 없음 (직접 계산)  
**증명 상태**: ✅ 검증 완료

**계산**:
- LHS: $1^3 = 1$
- RHS: $\left(\frac{2}{2}\right)^2 = 1^2 = 1$
- 결론: LHS = RHS ✓

---

### L7: 소규모 사례 검증 (Counterexample Check)
**명제**: $n = 1, 2, 3, 4, 5$에 대해 명제가 성립한다.

**분류**: 검증 보조정리 (Verification Lemma)  
**난이도**: 낮음  
**의존성**: 없음 (직접 계산)  
**증명 상태**: ❌ 미검증 — 검증 필요

**계산표**:

| $n$ | LHS: $\sum k^3$ | RHS: $\left(\frac{n(n+1)}{2}\right)^2$ | 일치 여부 |
|-----|----------------|----------------------------------------|----------|
| 1 | $1^3 = 1$ | $\left(\frac{1 \cdot 2}{2}\right)^2 = 1$ | ✅ |
| 2 | $1 + 8 = 9$ | $\left(\frac{2 \cdot 3}{2}\right)^2 = 9$ | ✅ |
| 3 | $1 + 8 + 27 = 36$ | $\left(\frac{3 \cdot 4}{2}\right)^2 = 36$ | ✅ |
| 4 | $1 + 8 + 27 + 64 = 100$ | $\left(\frac{4 \cdot 5}{2}\right)^2 = 100$ | ✅ |
| 5 | $1 + 8 + 27 + 64 + 125 = 225$ | $\left(\frac{5 \cdot 6}{2}\right)^2 = 225$ | ✅ |

**결론**: 반례 없음 (소규모 범위에서)
