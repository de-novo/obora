## 1. Gap 분류 체계

### 1.1 우선순위 정의
| 등급 | 정의 | 영향 | 조치 필요성 |
|------|------|------|-------------|
| **P0** | CRITICAL | 증명 완결성에 치명적 | 즉시 해결 필요 |
| **P1** | MODERATE | 증명 경로 차단 | 대안 경로 또는 보완 필요 |
| **P2** | MINOR | 투명성/완전성 저하 | 문서화로 완화 가능 |

### 1.2 Gap 유형 분류
- **Logical Gap**: 논리적 연결 누락
- **Algebraic Gap**: 대수적 조작의 불완전성
- **Epistemic Gap**: 지식/전제의 불명확성
- **Methodological Gap**: 방법론의 투명성 부족

## 2. P0 (CRITICAL) Gap 레지스터

### GAP-P0-001: 대수적 경로의 Faulhaber 의존성

**위치**: 
- 10-lemma-candidates.md, L-대수-002
- 11-proof-attempt.md, Section 3.2

**유형**: Epistemic Gap

**명제**: 
∑_{k=1}^{n} k³을 n의 다항식으로 표현할 수 있다.

**현재 상태**: 
❌ 미해결

**상세 설명**:
1. 대수적 증명 경로에서는 좌변 ∑k³과 우변 [n(n+1)/2]²을 직접 비교해야 함
2. 우변은 명시적 다항식: (n⁴ + 2n³ + n²)/4
3. 좌변을 다항식으로 표현하려면 Faulhaber 공식 필요
4. Faulhaber 공식의 p=3 특수 경우가 MC-001과 동치
5. 따라서 Faulhaber 사용은 순환 논증

**숨은 가정**:
- HA-001: ∑k³이 n의 4차 다항식임

**시도된 해결 방법**:
1. 수학적 귀납법 → ✅ 성공 (다른 경로)
2. 텔레스코핑 급수 → 🔶 부분 성공 (P1 Gap 존재)
3. 이산적적분 → ❌ 미시도
4. 생성 함수 → ❌ 미시도

**영향**:
- 대수적 증명 경로 완전 차단
- "순수 대수적" 접근 불가능

**완화 가능성**: 
🟡 중간
- 귀납법 경로가 이미 완료되었으므로 이 Gap은 "독립적 증명 경로"의 문제
- MC-001 자체는 이미 증명됨

**대안 경로**:
- 귀납법 경로 사용 (✅ 완료)
- 텔레스코핑 경로 사용 (🔶 P1 Gap 존재)

**우선순위 조정 제안**:
- 귀납법 증명 완료로 인해 P0 → P1 강등 가능
- 그러나 "다중 경로 증명" 목표에는 여전히 P0

### GAP-P0-002: 조합론적 해석의 부재

**위치**: 
- 10-lemma-candidates.md, L-조합-002
- 11-proof-attempt.md, Section 4

**유형**: Epistemic Gap

**명제**: 
[⊂(n+1,2)]² = ∑k³의 조합론적 의미가 존재한다.

**현재 상태**: 
❌ 미해결

**상세 설명**:
1. 좌변: ∑_{k=1}^{n} k³ = 1 + 8 + 27 + ... + n³
2. 우변: [⊂(n+1,2)]² = [(n+1)n/2]²
3. ⊂(n+1,2)는 (n+1)개 원소에서 2개를 선택하는 방법의 수
4. 이 제곱이 세제곱수 합과 어떻게 조합론적으로 대응되는지 불명확

**시도된 접근**:
1. n×n 격자에서의 패턴 counting → ❌ 실패
2. 3차원 큐브 배열 → ❌ NG-004로 제외됨
3. 문헌 조사 → ❌ 미수행

**영향**:
- 조합론적 증명 경로 완전 차단
- "직관적 이해" 제공 불가

**완화 가능성**: 
🔴 낮음
- 창의적 통찰 또는 문헌 발견 필요
- 귀납법/대수적 증명으로부터 자동 도출 안 됨

**대안**:
- 기하학적 증명 (큐브 피라미드) 재고
- 생성 함수 접근

**우선순위 조정 제안**:
- 귀납법 증명 완료로 인해 P0 → P2 강등 가능
- "조합론적 통찰"은 선택적 목표

## 3. P1 (MODERATE) Gap 레지스터

### GAP-P1-001: 텔레스코핑 항의 발견 방법론

**위치**: 
- 10-lemma-candidates.md, L-대수-003, L-대수-004
- 11-proof-attempt.md, Section 3.2 (시도 2)
- 12-counterexample-check.md, HA-008

**유형**: Methodological Gap

**명제**: 
k³ = [k(k+1)/2]² - [(k-1)k/2]²를 "발견적"으로 도출할 수 있다.

**현재 상태**: 
🔶 부분 해결

**상세 설명**:
1. 텔레스코핑 증명은 다음 항등식에서 출발:
   k³ = [k(k+1)/2]² - [(k-1)k/2]²
2. 이 항등식은 "역방향 검증"으로 확인됨
3. 그러나 "정방향 발견"의 논리적 경로가 불명확
4. "답을 알고 나서 증명을 구성"한 것 아닌가?

**숨은 가정**:
- HA-008: 텔레스코핑 항이 이미 알려진 결과로부터 "역설계"됨

**시도된 정당화**:
1. **유일성 검증**: g(k) = ak² + bk + c로 설정
   - [g(k)]² - [g(k-1)]² = k³이 되도록 계수 결정
   - 결과: g(k) = k(k+1)/2이 유일한 해
   - ✅ 유일성 확인됨

2. **동기 부여**:
   - k³이 "홀수들의 합"으로 표현 가능함은 잘 알려짐
   - k³ = k² + k(k-1) + k(k-1) + ... (기하학적 동기)
   - 이로부터 텔레스코핑 구조 추론 가능?

**영향**:
- 텔레스코핑 증명의 "발견적 가치" 저하
- "검증적 가치"는 여전히 유효
- 교육적 관점에서 "어떻게 생각해내는가?"가 불명확

**완화 가능성**: 
🟢 높음
- 유일성 검증으로 "임의성" 문제 해결
- 귀납법 증명이 이미 완료되어 텔레스코핑은 보조적 역할

**해결 방안**:
1. "동기 부여" 섹션 추가:
   - "k³을 연속된 제곱의 차로 표현하려는 시도에서 자연스럽게 도출"
   - "f(k) = ak² + bk + c로 설정 후 계수 비교"
2. 유일성 증명을 부록에 추가

**우선순위**: 
- 귀납법 증명 완료로 인해 P1 유지 (완화 쉬움)

### GAP-P1-002: 선행 계수 일치의 독립적 도출

**위치**: 
- 10-lemma-candidates.md, L-보조-003

**유형**: Epistemic Gap

**명제**: 
∑k³의 n⁴ 항 계수가 1/4임을 Faulhaber 없이 도출할 수 있다.

**현재 상태**: 
🔶 부분 해결

**상세 설명**:
1. 우변 [n(n+1)/2]²의 n⁴ 계수: 1/4 (명시적)
2. 좌변 ∑k³의 n⁴ 계수를 알려면 Faulhaber 필요
3. Faulhaber 없이 "선행 계수만" 도출하는 방법?

**시도된 접근**:
- 적분 근사: ∑k³ ≈ ∫x³ dx = n⁴/4
- 이는 "근사"이지 정확한 계수 도출 아님

**영향**:
- "다항식 차수/계수 일치"를 이용한 간접 증명 불가
- 완전한 대수적 독립성 확보 실패

**완화 가능성**: 
🟡 중간
- "적분 근사"로 직관 제공 가능
- 정확한 도출은 Faulhaber 또는 귀납법 필요

**해결 방안**:
- Euler-Maclaurin 공식으로 오차 항 분석
- 또는 이 Gap을 "선행 지식"으로 인정하고 문서화
