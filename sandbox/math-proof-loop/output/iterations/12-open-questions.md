# 열린 질문 (Open Questions)

## 미해결 질문

### Q-001: 카운터 초기화 조건
- **대상**: no-progress counter, repeated issue counter
- **질문**: 언제 카운터가 초기화되는가? (성공 시? 부분 개선 시?)
- **영향**: 수렴 가설(H-002) 검증, 종료 조건 정확도
- **우선순위**: 높음

### Q-002: P0/P1 이슈 정의 기준
- **대상**: 리뷰 단계의 이슈 분류
- **질문**: "치명적(P0)"과 "비치명적(P1)"의 구체적 기준은 무엇인가?
- **영향**: 검증 기준 모호성 위험(R-004) 해결, 외부 타당성 검증
- **우선순위**: 높음

### Q-003: 진전(progress) 판단 기준
- **대상**: no-progress 판정 로직
- **질문**: "실질 개선"을 어떻게 정량적/정성적으로 판단하는가?
- **영향**: 종료 조건의 정확도, 의사 수렴 위험(R-002) 완화
- **우선순위**: 중간

### Q-004: iteration별 컨텍스트 유지율 실측
- **대상**: 컨텍스트 붕괴 가설(H-003)
- **질문**: iteration 1-5에서 핵심 용어/판단 기준이 얼마나 유지되는가?
- **영향**: iteration 상한(max=5)의 적정성 판단
- **우선순위**: 중간

- 남은 과제: 진전 판단 기준 명시 (Q-003)

### H-003: 컨텍스트 붕괴 가설 → 검증 보류
- 남은 과제: iteration 실행 및 유지율 측정 (Q-004)
