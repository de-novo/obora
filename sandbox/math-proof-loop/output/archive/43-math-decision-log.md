### Decision 2: Known Facts 범위 설정

**일시**: 초기 단계  
**결정**: **F1-F12를 Known Facts로 설정**, 재증명하지 않음

**고려사항**:
- Field Axioms (F1-F6) → 재증명 비실용적
- Induction Principle (F7-F8) → 명시적 가정으로 처리
- Algebraic Identities (F9-F12) → Field Axiom에서 유도 가능

**근거**:
- "axiom-adjacent" 수준의 기본 성질
- 재증명은 본 문제 범위를 벗어남
- 명시적 목록으로 투명성 확보

**결과**: ✅ 타당 (P1 Gap 없음)

### Decision 3: 도메인 범위 설정

**일시**: 문제 정의 단계  
**결정**: **$n \geq 1$ (양의 정수)** 로 제한

**고려사항**:
- $n=0$에서도 성립함이 확인됨
- 그러나 명제는 "양의 정수"에 초점

**근거**:
- 전통적인 정식화와 일치
- $n=0$은 empty sum으로 별도 처리 필요 가능성
- P2-3으로 명시적 기록

**결과**: ✅ 타당 (확장 가능)

---

### Decision 4: 계산 검증 범위

**일시**: 검증 단계  
**결정**: **$n=1$~$100$** 까지 계산 검증

**대안**:
1. $n=1$~$10$ (최소)
2. $n=1$~$100$ ← **선택**
3. $n=1$~$1000$ (과도)

**근거**:
- 100개 케이스로 충분한 신뢰 확보
- 귀납법으로 일반화되므로 과도한 검증 불필요
- 연산 시간 합리적

**결과**: ✅ 반례 없음 확인

---

### Decision 5: 숨은 가정 H3 명시적 검증

**일시**: Review 단계  
**결정**: **H3 ($n(n+1)$은 짝수) 명시적 검증**

**문제**: $\frac{n(n+1)}{2}$가 정수라는 보장이 명시되지 않음

**근거**:
- 잠재적 P1 Gap 후보로 식별
- 명시적 검증으로 타당성 확보
- Case analysis로 완전 증명 가능

**검증**:
- Case 1: $n$이 짝수 → $n = 2k$ → $n(n+1) = 2k(n+1)$ → 2의 배수 ✓
- Case 2: $n$이 홀수 → $n+1$이 짝수 → $n+1 = 2k$ → $n(n+1) = 2kn$ → 2의 배수 ✓

**결과**: ✅ P1 아님으로 판정

---

### Decision 6: P2 Gap 분류

**일시**: Review 단계  
**결정**: **4개 Gap을 P2 (Minor)로 분류**, P0/P1 아님

**식별된 Gap**:
1. P2-1: 변수 명명 혼용
2. P2-2: "직접 계산" 과정 생략
3. P2-3: $n=0$ 경계 조건 미명시
4. P2-4: Known Facts 출처 불명확

**근거**:
- 모든 Gap이 증명의 타당성에 영향을 주지 않음
- 개선 권장사항 수준
- 치명적이지 않음

**결과**: ✅ P0/P1 Gap 없음으로 최종 판정
