# Methodology

## 연구 방법론

본 연구는 수학적 증명의 체계적 검증을 위해 Obora 워크플로우를 적용했다.

---

## 1. 문제 정의 및 구조화

### 1.1 명제 형식화

자연수 $n$에 대한 세제곱 합 공식을 수학적 귀납법으로 증명 가능한 형태로 구조화:

$$P(n): \sum_{k=1}^{n} k^3 = \left( \frac{n(n+1)}{2} \right)^2$$

### 1.2 증명 전략 수립

- **주 경로**: 표준 수학적 귀납법 (Base case + Inductive step)
- **대안 경로**: 양변 증가분 비교 (직접 전개)

---

## 2. 증명 수행

### 2.1 수학적 귀납법 적용

| 단계 | 내용 | 검증 상태 |
|------|------|-----------|
| Base Case | $n=1$일 때 등식 성립 확인 | ✅ 완료 |
| Inductive Hypothesis | $P(n)$ 가정 | ✅ 명시됨 |
| Inductive Step | $P(n) \Rightarrow P(n+1)$ 증명 | ✅ 완료 |

### 2.2 대안 증명 경로

양변의 $n \to n+1$ 증가분이 동일함을 보이는 독립적 검증:

$$\left( \frac{(n+1)(n+2)}{2} \right)^2 - \left( \frac{n(n+1)}{2} \right)^2 = (n+1)^3$$

---

## 3. 검증 프레임워크

### 3.1 Proof Gap 식별

Obora의 Proof Gap Register를 사용하여 증명 과정의 누락 단계를 체계적으로 식별:

| 심각도 | 정의 | 탐지 방법 |
|--------|------|-----------|
| P0 (Critical) | 논리적 오류, 결론 무효화 | 논리 구조 분석 |
| P1 (Major) | 중요 단계 생략 | 중간 전개 검토 |
| P2 (Minor) | 사소한 생략 | 완전성 체크 |

### 3.2 반례 탐색

다음 범주에서 반례 존재 여부 검증:

1. **정의역 경계**: $n=1, n=2$ 등 특이점
2. **귀납 단계 실패**: $P(n) \not\Rightarrow P(n+1)$인 경우
3. **대수적 반례**: 양변 값이 다른 $n$ 존재
4. **특이값**: 극한, 발산 등

### 3.3 일관성 검사

- Lemma 간 논리적 일관성
- Base case ↔ Inductive step 연결
- 주 경로 ↔ 대안 경로 결과 일치

## 4. Review-Remediation 루프

### 4.1 Review 단계

- 증명 완결성 평가
- Gap 심각도 분류
- 반례/일관성 검증

### 4.2 Remediation 단계

- P0/P1 Gap 해결 방안 수립
- 선택적 vs 필수 remediation 구분
- 해결 후 재검증
