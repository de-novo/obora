# Draft

## Summary

Obora의 세 번째 canonical sandbox를 구축하여 brief → draft → validation 워크플로우를 시연한다.

## Key Points

- **Brief 수집**: brief.md에서 요구사항을 읽어온다.
- **Draft 생성**: 요구사항을 바탕으로 구조화된 초안을 작성한다.
- **Validator 실행**: 체크리스트 기반으로 draft를 자동 검증한다.
- **결과 표시**: PASS/FAIL 여부가 명확히 드러나도록 결과를 출력한다.

## Next Action

- validator 스텝에서 draft 체크리스트 검증 로직을 구현하고, PASS/FAIL 결과를 기록한다.
