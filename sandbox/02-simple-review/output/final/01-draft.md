# 01-draft.md

## Draft Summary

Obora의 두 번째 canonical sandbox를 구축합니다. 이 샌드박스는 간결하고 구조적인 문서 작성 프로세스를 보여주는 것을 목표로 합니다.

프로세스 흐름:
1. Brief를 기반으로 초안 문서 작성
2. Reviewer가 초안 검토 (강점/문제점/개선점 정리)
3. Reviewer가 개선된 최종 문서 작성

## Key Points

- **Canonical sandbox**: Obora의 표준 샌드박스 패턴을 따르는 두 번째 예제
- **3단계 문서화 프로세스**: 초안 → 검토 → 최종 문서
- **간결성과 구조성**: 모든 문서는 짧고 명확한 구조를 유지
- **명확한 역할 분담**: 작성자(초안)와 검토자(리뷰 및 최종)의 책임 분리

## Open Questions

1. 이 샌드박스에서 다룰 구체적인 주제나 도메인이 정해져 있는가?
2. Reviewer의 피드백을 몇 회까지 반복할 수 있는가? (1회성인지, 반복 개선인지)
3. 최종 문서의 형식이나 템플릿이 별도로 정의되어 있는가?
4. 검토 기준(강점/문제점/개선점 외 추가 항목)이 있는가?
