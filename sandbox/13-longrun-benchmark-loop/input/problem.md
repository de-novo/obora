# Problem

Obora의 열세 번째 canonical sandbox를 위해 작은 long-running benchmark loop 문제를 푼다.

질문:
- A deployment window lasts **48 minutes** and is split into **4 equal phases**.
- How many minutes does each phase last?

제약:
- 답은 단일 숫자로 명확히 제시한다.
- reasoning은 짧고 간단해야 한다.
- initial attempt는 의도적으로 틀린 답을 제시해 첫 judge verdict가 FAIL이 되도록 한다.
