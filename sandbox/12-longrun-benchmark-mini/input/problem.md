# Problem

Obora의 열두 번째 canonical sandbox를 위해 아주 작은 long-running benchmark 문제를 푼다.

질문:
- A maintenance window lasts **45 minutes** and is split into **3 equal phases**.
- How many minutes does each phase last?

제약:
- 답은 단일 숫자로 명확히 제시한다.
- reasoning은 짧고 간단해야 한다.
- solver는 reference answer를 보면 안 된다.
