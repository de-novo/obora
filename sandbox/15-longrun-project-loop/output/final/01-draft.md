# Project Draft: Sandbox 15 - Long-Running Project Loop

## Project Summary
Create the 15th canonical sandbox demonstrating a long-running project remediation loop on Obora's runner. This sandbox will showcase a complete lifecycle: draft creation, review, validation failure detection, repair, final validation, and archive generation. The implementation emphasizes short, structured documentation with reusable archive artifacts.

## Scope
**In Scope:**
- Draft generation with intentional validation failure trigger
- Review step identifying missing required sections
- Repair step adding omitted content
- Final validation confirming compliance
- Archive note generation for reuse

**Out of Scope:**
- Multi-language support
- External API integrations
- Performance benchmarking
