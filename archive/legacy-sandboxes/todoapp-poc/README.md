# TodoApp PoC Sandbox

> 상태: **legacy / 참고용 sandbox**
>
> 이 폴더는 현재 canonical sandbox 기준이 아닙니다. product planning / development workflow를 실험하기 위한 TodoApp PoC 목적의 sandbox입니다.

## 목적
- planning workflow와 development workflow를 분리해 실험
- product/architecture/QA 역할 orchestration 확인
- PRD/릴리즈 게이트류의 장문 step 흐름 검증

## 주요 설정
- `.obora/config.yaml`
- `.obora/agents.yaml`
- `.obora/workflows/todo-planning-10.yaml`
- `.obora/workflows/todo-dev-10.yaml`

## 비고
planning/dev 사다리형 구조를 시험하기 위한 샌드박스였지만, 현재는 구조 재설계 이전의 실험 자산으로 간주합니다.
