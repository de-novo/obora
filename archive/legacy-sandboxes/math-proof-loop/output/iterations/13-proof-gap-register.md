# 13 — Proof Gap Register

## 개요

본 문서는 Aletheia Benchmark 01 문제 증명 과정에서 발견된 **모든 proof gap**를 체계적으로 등록하고 분류한다. 각 gap은 심각도(P0/P1/P2), 위치, 원인, 해결 전략을 포함한다.

---

## Gap 분류 체계

### 심각도 정의

| 등급 | 정의 | 기준 |
|------|------|------|
| **P0 (Critical)** | 증명 전체를 무효화 | 논리적 모순, 잘못된 추론, 해결 불가능한 구조적 결함 |
| **P1 (Major)** | 핵심 단계 무효화 | 증명되지 않은 핵심 명제, 생략된 중요 논증 |
| **P2 (Minor)** | 엄밀성 부족 | 자명하다고 가정한 단계, 세부 검증 필요 |

## P0 (Critical) Gaps

### GAP-P0-001: Proof Attempt 2의 구조적 결함

**위치**: 11-proof-attempt.md, Step 2-8

**발견자**: 12-counterexample-check.md (CONSISTENCY-1)

**내용**:
> 모순법 증명(Proof Attempt 2)에서 Step 2-8의 모순 도출이 **근본적으로 불가능**함. 지수 관계에서 \(\frac{(1+\epsilon)^3}{(1+\epsilon')^4} < 1\)이면 우변이 0으로 수렴하여 모순이 발생하지 않음.

**상세 분석**:
```
Step 2-6: q q_N > (1+ε)^{3·2^{N+1}}
Step 2-7: q_N ≤ C · a_{N+1}^2 (미증명)
Step 2-8: q C a_{N+1}^2 > (1+ε)^{3·2^{N+1}}

가정: a_{N+1} < (1+ε')^{2^{N+1}}

결과: q C > [(1+ε)^3 / (1+ε')^4]^{2^N}

문제: ε' ≥ ε이면 [(1+ε)^3 / (1+ε')^4] ≤ [(1+ε)^3 / (1+ε)^4] = 1/(1+ε) < 1
      우변이 0으로 수렴 → 모순 없음
```

**원인**:
1. 잘못된 지수 설계: \(a_{N+1}^2\)와 \((1+\epsilon)^{3 \cdot 2^{N+1}}\)의 비교가 모순을 생성하지 않음
2. 성장률 불일치: \(a_{N+1} \sim (1+\epsilon)^{2^{N+1}}\)이면 \(a_{N+1}^2 \sim (1+\epsilon)^{2^{N+2}}\), 이는 \((1+\epsilon)^{3 \cdot 2^{N+1}}\)보다 작음

**해결 가능성**: ❌ **불가능** (구조적 결함)

**대안 전략**:
1. Proof Attempt 2 완전 폐기
2. 다른 모순법 구조 설계 (예: \(q_N\) 대신 다른 변수 사용)
3. 직접 증명 전략으로 전환

**우선순위**: 즉시 포기 필요

### GAP-P0-002: 근사에 의한 무리수성 보존 불가

**위치**: 11-proof-attempt.md, Step 3-1 (Proof Attempt 3)

**발견자**: 11-proof-attempt.md (GAP-3-1-1)

**내용**:
> "일반 수열을 특수 수열로 근사하면 무리수성이 보존된다"는 명제가 **거짓**임.

**상세 분석**:
- 무리수 \(\alpha\)에 대해 \(\alpha + (\text{유리수} - \alpha) = \text{유리수}\)
- 작은 perturbation이 무리수성을 보존하지 않음
- **연속성이 무리수성에는 적용되지 않음**

**원인**: 무리수성은 위상적 성질이 아닌 대수적 성질

**해결 가능성**: ❌ **불가능** (근본적 오류)

**대안 전략**: Proof Attempt 3 완전 폐기

**우선순위**: 즉시 폐기

### GAP-P0-003: L-4의 진법 존재성 미보장

**위치**: 10-lemma-candidates.md, L-4 (GAP-L4-1)

**발견자**: 10-lemma-candidates.md

**내용**:
> 일반 수열 \((a_n)\)에 대해 "어떤 정수 \(b \geq 2\)가 존재하여 \(S\)의 \(b\)-진 전개가 비주기적"이라는 보장이 없음.

**상세 분석**:
- 특수 수열 \(a_n = c^{2^n}\)에서는 \(b = c\)로 선택 가능
- 일반 수열에서는:
  - \(a_n a_{n+1}\)이 \(b\)의 거듭제곱 꼴이 아님
  - \(b\)-진 전개가 깔끔하지 않음
  - 모든 \(b\)에 대해 주기적일 가능성 배제 불가

**원인**:
1. 특수 수열과 일반 수열의 구조적 차이
2. 진법 전개 방법의 일반화 불가

**해결 가능성**: ⚠️ **매우 어려움**

**대안 전략**:
1. L-4 포기, 다른 일반화 방법 탐색
2. 소인수 분해 구조 활용
3. Diophantine 근사 이론 사용

**우선순위**: 장기 과제

## P1 (Major) Gaps

### GAP-P1-001: c-진법 전개의 주기성 부재 미증명

**위치**: 11-proof-attempt.md, Step 1-4 (GAP-1-4-1)

**발견자**: 11-proof-attempt.md

**내용**:
> 특수 수열 \(a_n = c^{2^n}\)에서 급수 \(S = \sum_{n=1}^{\infty} c^{-3 \cdot 2^n}\)의 \(c\)-진 전개가 주기적이지 않음이 **엄밀히 증명되지 않음**.

**상세 분석**:
- 직관: 1의 위치가 \(3 \cdot 2^n\)으로 지수적 성장 → 주기성 불가능
- 문제: "불가능"의 엄밀한 증명 생략

**증명 스케치 (가능)**:
```
귀류법: 주기 T가 존재한다 가정

Case 1: T = 0 (자명한 주기) → 무의미

Case 2: T > 0
  - 어떤 N₀ ≥ 1이 존재하여 n ≥ N₀에 대해 d_{n+T} = d_n
  - d_{3·2^n} = 1 for all n ≥ 1
  - 주기성에 의해 d_{3·2^n + T} = d_{3·2^n} = 1
  - 따라서 3·2^n + T = 3·2^m for some m (n이 충분히 클 때)
  - T = 3·2^m - 3·2^n = 3·2^n(2^{m-n} - 1)
  
  모든 n ≥ N₀에 대해 위 식이 성립해야 함
  n과 n+1에 대해:
    T = 3·2^n(2^{m-n} - 1) = 3·2^{n+1}(2^{m'-n-1} - 1)
    2^{m-n} - 1 = 2(2^{m'-n-1} - 1)
    
  이것이 모든 n에 대해 성립하려면 m = n + 1, m' = n + 2
    T = 3·2^n(2 - 1) = 3·2^n
    T = 3·2^{n+1}(2 - 1) = 3·2^{n+1}
    
  모순: T = 3·2^n = 3·2^{n+1}은 n이 다르면 성립하지 않음
```

**원인**: 증명 생략

**해결 가능성**: ✅ **가능** (귀류법으로 증명 가능)

**해결 전략**:
1. 위 스케치를 엄밀하게 작성
2. 모든 edge case 처리
3. 보조정리로 분리하여 증명

**우선순위**: **최우선** (Proof Attempt 1 완성의 핵심)

### GAP-P1-003: 부분합 분모 \(q_N\)의 성장 상한

**위치**: 11-proof-attempt.md, Step 2-7 (GAP-2-7-1)

**발견자**: 11-proof-attempt.md

**내용**:
> \(q_N \leq C \cdot a_{N+1}^2\) 상한이 **증명되지 않음**.

**상세 분석**:
- \(q_N \mid a_1 a_2 \cdots a_{N+1}\)은 성립
- 하지만 \(a_1 \cdots a_N\)이 \(a_{N+1}^2\)보다 클 수 있음

**12-counterexample-check.md에서의 분석**:
```
초지수적 성장: a_n > (1+ε)^{2^n} for n ≥ N₀

a₁ ··· a_N ≈ (1+ε)^{2^1 + ··· + 2^N} = (1+ε)^{2^{N+1} - 2}

a_{N+1}² ≈ [(1+ε)^{2^{N+1}}]² = (1+ε)^{2^{N+2}}

비교: 2^{N+1} - 2 < 2^{N+2} (N이 충분히 클 때)

따라서 a₁ ··· a_N < a_{N+1}² (가능)
```

**원인**: 증명 생략

**해결 가능성**: ✅ **가능** (초지수적 성장 조건으로 증명 가능)

**해결 전략**:
1. \(a_1 \cdots a_N < a_{N+1}^2\)를 엄밀히 증명
2. \(q_N \leq a_1 \cdots a_{N+1} < 2 a_{N+1}^2\) (상수 2는 \(a_{N+1}\)이 충분히 클 때)

**주의**: 이 gap을 해결해도 GAP-P0-001 때문에 모순 도출 불가

**우선순위**: 중기 (GAP-P0-001 해결 방법 탐색 후 결정)

## P2 (Minor) Gaps

### GAP-P2-001: Carry 발생하지 않음 확인

**위치**: 11-proof-attempt.md, Step 1-3 (GAP-1-3-1)

**발견자**: 11-proof-attempt.md

**내용**:
> \(S = \sum_{n=1}^{\infty} c^{-3 \cdot 2^n}\)에서 각 항이 서로 다른 자리에 1을 더하므로 carry가 발생하지 않음을 확인.

**상세 분석**:
- \(c^{-3 \cdot 2^n}\)은 소수점 이하 \(3 \cdot 2^n\)번째 자리에 1
- \(3 \cdot 2^n < 3 \cdot 2^{n+1}\)이므로 자릿수가 겹치지 않음
- 따라서 단순 합에서 carry 없음

**원인**: 자명하다고 가정

**해결 가능성**: ✅ **매우 쉬움**

**해결 전략**:
1. 보조정리: "서로 다른 자릿수에 1을 더하는 합에서 carry 없음"
2. 1-2줄로 증명 가능

**우선순위**: 낮음 (자명)
