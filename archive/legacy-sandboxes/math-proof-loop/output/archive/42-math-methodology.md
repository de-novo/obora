## 2. 문제 정의 방법론

### 2.1 Problem Frame 구성 요소

1. **원문제 진술**: 명확하고 모호함 없는 수학적 명제
2. **성장 조건 분석**: \(\liminf a_n^{1/2^n} > 1\)의 의미 해석
3. **접근 전략 식별**: 다각적 접근 경로 나열
4. **Non-Goals 설정**: 탐색 범위 명시적 한정
5. **성공 기준 정의**: 해결/부분해결/실패의 명확한 기준

### 2.2 적용 예시

```
원문제: "S가 항상 무리수인가?"

접근 전략:
  - 특수 수열에서 직접 증명
  - 모순법 (유리수 가정)
  - 구조적 접근 (진법 전개)
  - 반례 탐색

Non-Goals:
  - 완전한 일반 증명 (초기 목표 아님)
  - 문헌의 완전한 조사
```

## 3. Known Results Audit 방법론

### 3.1 지식 분류 체계

1. **Known Facts (KF)**: 확립된 수학적 사실
   - 인용 가능한 정리
   - 표준 교재의 결과
   - 자명한 사실

2. **Permissible Assumptions (PA)**: 탐색 중 가정 가능한 명제
   - 표준 수론 배경지식
   - 탐색 범위 내에서 받아들일 명제

3. **Unknowns (U)**: 해결되지 않은 관련 문제
   - 향후 탐색 방향
   - 리스크 요소

### 3.2 적용 예시

```
Known Facts:
  KF-1: 유리수의 b-진 전개는 주기적
  KF-2: S = (1/a₁) - lim(1/a_n) (telescoping)

Permissible Assumptions:
  PA-1: 정수의 산술적 성질
  PA-2: 급수의 수렴성 (성장 조건 하에서)

Unknowns:
  U-1: 일반 수열에서 진법 전개 구조
  U-2: Erdős-Borwein 상수의 무리수성
```

## 4. Lemma 후보 식별 방법론

### 4.1 Lemma 분류

| 유형 | 정의 | 예시 |
|------|------|------|
| **Foundational** | 증명의 기초가 되는 명제 | L-1: 급수 형태 단순화 |
| **Core** | 증명의 핵심 논증 | L-2: 특수 수열 무리수성 |
| **Bridging** | 특수에서 일반으로 연결 | L-4: 일반화된 진법 전개 |
| **Supporting** | 보조적 역할 | L-6: 성장 조건 최적성 |

### 4.2 Lemma 의존성 분석

```
L-1 (특수 수열 급수 형태)
  └── L-2 (특수 수열 무리수성)
        ├── GAP-P1-001 (주기성 부재)
        └── GAP-P2-001 (Carry 확인)

L-3 (유리수 근사 하한)
  └── L-5 (부분합 분모 구조)
        └── GAP-P1-003 (q_N 성장 상한)

L-2 + L-4
  └── 일반화 시도
        └── GAP-P0-003 (진법 존재성)
```

## 5. Proof Attempt 방법론

### 5.1 증명 전략 분류

1. **직접 증명 (Direct Proof)**
   - 명제의 결론을 직접 도출
   - 예: 특수 수열에서 \(c\)-진법 전개 이용

2. **모순법 (Proof by Contradiction)**
   - 결론의 부정으로부터 모순 도출
   - 예: \(S = p/q\) 가정 후 모순

3. **구조적 접근 (Structural Approach)**
   - 대상의 구조적 성질 이용
   - 예: 진법 전개의 주기성

4. **근사법 (Approximation)**
   - 특수 경우로의 근사
   - 예: 일반 수열을 특수 수열로 근사

### 5.2 Proof Attempt 템플릿

```markdown
## Proof Attempt X: [제목]

### 접근 전략
[전략 설명]

### 증명 스케치
1. Step 1: [내용]
2. Step 2: [내용]
...

### 식별된 Gap
- GAP-X-Y: [내용]

### 평가
- 타당성: [높음/중간/낮음]
- 완료도: [X%]
- 해결 가능성: [가능/어려움/불가능]
```

## 6. 반례 및 숨은 가정 분석 방법론

### 6.1 반례 탐색 전략

1. **경계 조건 탐색**
   - 조건이 등호를 만족하는 경우
   - 조건에 가까운 경우

2. **극단적 예시**
   - 최소/최대 성장률
   - 특수 구조

3. **수치적 실험**
   - 구체적 수열에서 계산
   - 유리수 후보와 비교

4. **구조적 반례 구성**
   - 명제를 무효화하는 구조 설계

### 6.2 숨은 가정 식별

각 Proof Attempt에서:

1. **명시적 단계 검토**: "자명", "명확" 등의 표현 식별
2. **논리적 점프 검토**: 생략된 추론 단계
3. **외부 지식 검토**: 표준 정리의 적용 가능성
4. **의존성 검토**: 다른 단계와의 연결

### 6.3 적용 예시

```
Proof Attempt 1에서의 숨은 가정:
  HIDDEN-1-1: Carry 발생 안 함
    → 검증 결과: 타당 (자릿수 겹치지 않음)
  HIDDEN-1-2: 주기성 부재 자명
    → 검증 결과: 증명 필요 (GAP-P1-001)
```

## 7. Proof Gap Register 방법론

### 7.1 Gap 분류 체계

| 등급 | 정의 | 기준 | 액션 |
|------|------|------|------|
| **P0 (Critical)** | 증명 전체 무효화 | 논리적 모순, 구조적 결함 | 즉시 폐기 또는 재설계 |
| **P1 (Major)** | 핵심 단계 무효화 | 미증명 명제, 생략된 논증 | 우선 해결 |
| **P2 (Minor)** | 엄밀성 부족 | 자명 가정, 세부 검증 | 단기 해결 |

### 7.2 Gap 등록 템플릿

```markdown
### GAP-[심각도]-[번호]: [제목]

**위치**: [문서, 단계]
**발견자**: [문서]
**내용**: [상세 설명]
**원인**: [왜 발생했는가]
**해결 가능성**: [가능/어려움/불가능]
**해결 전략**: [구체적 방법]
**우선순위**: [즉시/단기/중기/장기]
```

### 7.3 Gap 의존성 관리

```
GAP-P1-001 (주기성 부재)
    ↓ 해결 시
GAP-P1-006 (예시 주기성) 자동 해결
    ↓
GAP-P2-002 (무리수 결론) 자동 완료
```

## 8. Review 및 Finalize 방법론

### 8.1 리뷰 체크리스트

- [ ] 논리적 흐름의 일관성
- [ ] Known Facts와의 정합성
- [ ] 모든 Gap의 식별 및 분류
- [ ] 반례 탐색의 완결성
- [ ] 숨은 가정의 명시적 검증

### 8.2 분류 기준

| 분류 | 정의 | 본 탐색 해당 여부 |
|------|------|-------------------|
| **solved** | 원 문제 완전 증명 | ❌ |
| **partially_supported** | 특수 경우 증명 또는 강력한 증거 | ✅ |
| **unresolved** | 유의미한 진전 없음 | ❌ (특수 수열 진전 있음) |
| **refuted** | 반례 발견 | ❌ |

### 8.3 Archiveable 판정 기준

1. ✅ 탐색 과정의 완결성
2. ✅ 성과와 한계의 명확한 구분
3. ✅ 향후 연구를 위한 로드맵
4. ✅ 솔직한 보고
5. ✅ 재현 가능성

## 10. 방법론의 강점과 약점

### 10.1 강점

1. **체계성**: 각 단계가 명확히 정의됨
2. **재현 가능성**: 다른 연구자가 동일 과정 수행 가능
3. **완결성**: 탐색의 시작과 끝이 명확
4. **투명성**: 모든 결정 과정이 문서화됨
5. **확장성**: 다른 문제에 적용 가능

### 10.2 약점

1. **시간 소요**: 체계적 문서화에 시간 필요
2. **완전성 착시**: 모든 경로를 탐색했다는 착각 가능
3. **문헌 의존**: 실제 문헌 조사는 별도 수행 필요
4. **전문가 필요**: 복잡한 Gap은 전문가 판단 필요

## 11. 향후 개선 방향

1. **자동화 도구**: Gap 추적, 의존성 분석 자동화
