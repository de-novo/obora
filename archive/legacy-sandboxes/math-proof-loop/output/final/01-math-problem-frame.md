# 01 — 수학 문제 프레임 정의

## 문제 정의

**원문제 (Aletheia Benchmark 01)**

> \(a_1 < a_2 < \cdots\)가 정수열이고
> \[
> \liminf a_n^{1/2^n} > 1
> \]
> 을 만족할 때,
> \[
> \sum_{n=1}^{\infty} \frac{1}{a_n a_{n+1}}
> \]
> 이(가) 항상 무리수인가?

**한국어 재진술**

증가하는 양의 정수열 \( (a_n)_{n \geq 1} \)이 조건
\[
\liminf_{n \to \infty} a_n^{1/2^n} > 1
\]
을 만족한다고 하자. 이때 급수
\[
S := \sum_{n=1}^{\infty} \frac{1}{a_n a_{n+1}}
\]
는 항상 무리수인가?

---

## Conjecture / Target Statement

**표적 명제 (Conjecture C)**

> 조건 \( \liminf a_n^{1/2^n} > 1 \)을 만족하는 모든 증가 정수열 \( (a_n) \)에 대하여, 급수 \( S = \sum_{n=1}^{\infty} \frac{1}{a_n a_{n+1}} \)은(는) 무리수이다.

**표적 유도형 (Target Derivatives)**

1. **강한 형태 (Stronger C')**: \( S \)가 더 강력한 초월수 조건을 만족한다.
2. **약한 형태 (Weaker C'')**: 무리수이거나 특정 유리수 형태로만 표현 가능하다.
3. **반례 존재성 (Refutation R)**: 조건을 만족하면서 \( S \)가 유리수인 수열이 존재한다.

이번 루프에서는 C를 표적으로 설정하며, C', C'', R은 보조·대안 명제로 둔다.

---

## Assumptions

### 명시적 가정 (Explicit Assumptions)

1. **수열 정의**
   - \( (a_n)_{n \geq 1} \)은(는) 양의 정수열이다.
   - \( a_1 < a_2 < \cdots \) (엄격히 증가).

2. **성장 조건**
   - \( \liminf_{n \to \infty} a_n^{1/2^n} > 1 \).
   - 이는 \( a_n \)이 초지수적(super-exponential)으로 성장함을 의미한다.
   - 구체적으로, 어떤 \( \epsilon > 0 \)과 \( N \)이 존재하여 모든 \( n \geq N \)에 대해
     \[
     a_n > (1 + \epsilon)^{2^n}.
     \]

3. **급수 수렴**
   - \( S = \sum_{n=1}^{\infty} \frac{1}{a_n a_{n+1}} \)은(는) 수렴한다 (성장 조건에서 자명).

### 숨은 가정 (Implicit Assumptions) — 검증 필요

1. **수열의 일반성**: 특별한 산술적 구조(예: 거듭제곱 수열, 소수 수열 등)를 가정하지 않음.
2. **정수성의 역할**: \( a_n \in \mathbb{Z} \) 조건이 무리수 성질에 결정적인지, 실수열로 확장 가능한지 불확실.
3. **2^n 지수의 의미**: \( 1/2^n \) 지수가 최적인지, 다른 지수에서도 성질이 유지되는지 미확인.

### 알려진 결과 (Known Results) — 초기 감사

1. **기본 수렴성**: 초지수적 성장 조건에서 급수는 절대 수렴.
2. **유리수 판별 일반 이론**: 무한 급수의 무리수성은 일반적으로 어려운 문제 (예: \( \zeta(2) = \pi^2/6 \)의 무리수성은 해결되었으나 일반화는 어려움).
3. **관련 정리**: 
   - Liouville 수의 초월성 (느리게 성장하는 분수 급수)
   - Roth 정리 (대수적 수의 유리 근사)
   - Erdős 문제들 (정수열의 산술적 성질)
4. **본 문제의 난이도**: Aletheia Benchmark로 등재됨 → 공개된 해결책 없음 가능성.

## Non-Goals

### 이번 iteration에서 추구하지 않는 것

1. **실제 난제 해결**
   - 이 문제가 미해결 난제일 경우, 증명을 완성하는 것을 목표로 하지 않음.
   - 대신, 탐색 루프의 운영 가능성을 검증함.

2. **완전한 증명 완성**
   - 모든 세부 lemma를 완벽히 증명하는 것이 아님.
   - 증명 구조, 필요한 lemma, 잠재적 공백을 식별하는 것을 목표로 함.

3. **수치 실험**
   - 특정 수열에 대한 수치적 계산은 보조 수단으로만 사용.
   - 수치적 증거가 수학적 증명을 대체하지 않음.

4. **일반화**
   - 조건을 완화하거나 문제를 확장하는 것은 이후 iteration에서 고려.
   - 이번에는 원문제에 집중.

5. **알고리즘 개발**
   - 무리수 판별 알고리즘을 개발하는 것이 아님.
   - 수학적 증명 구조를 탐색하는 것임.

### 범위 외 사항

- 다른 Aletheia Benchmark 문제로의 확장
- 실제 수학 저널 투고 준비
- 증명 보조기(coq, lean) 형식화 (향후 가능)

## 이번 Iteration의 성공 조건

### 필수 성공 조건 (Must Have)

1. **문제 구조화 완료**
   - [ ] Conjecture C가 명확히 정의됨 (위에서 완료)
   - [ ] 성장 조건의 수학적 의미가 분석됨
   - [ ] 적어도 3개 이상의 접근 전략이 식별됨

2. **Known Results Audit**
   - [ ] 관련된 알려진 정리/보조정리가 최소 5개 이상 나열됨
   - [ ] 각 정리가 본 문제에 미칠 수 있는 영향이 논의됨
   - [ ] 문헌 검색 키워드가 명시됨

3. **Lemma 후보 생성**
   - [ ] 적어도 3개 이상의 lemma 후보가 제안됨
   - [ ] 각 lemma의 필요성과 증명 난이도가 평가됨
   - [ ] lemma 간의 의존 관계가 파악됨

4. **초기 Proof Attempt**
   - [ ] 적어도 1개 이상의 증명 경로가 시도됨
   - [ ] 증명 도중 발생하는 논리적 간격(gap)이 명시됨
   - [ ] 사용된 기법이 기록됨

5. **Counterexample / Consistency Check**
   - [ ] 조건을 만족하는 간단한 수열 예시가 최소 2개 생성됨
   - [ ] 각 예시에 대해 S가 실제로 무리수인지 점검 (수치적/이론적)
   - [ ] 반례 가능성이 체계적으로 탐색됨

6. **Gap 분석**
   - [ ] 발견된 모든 증명 공백이 "proof-gap register"에 등록됨
   - [ ] 각 gap의 심각도가 평가됨 (critical/major/minor)
   - [ ] gap 해결을 위한 전략이 제안됨

7. **Review & Remediation**
   - [ ] 자체 review에서 논리적 비약, 숨은 가정, 반례 가능성이 점검됨
   - [ ] remediation이 단순 재서술이 아님
   - [ ] 개선된 증명 시도가 문서화됨

### 권장 성공 조건 (Should Have)

8. **의사결정 로그**
   - [ ] 주요 전략 선택의 이유가 기록됨
   - [ ] 시도한 접근과 실패한 접근이 구분됨

9. **중간 결론 도출**
   - [ ] 현재까지의 증명 상태가 요약됨
   - [ ] 다음 단계에서 집중해야 할 영역이 식별됨

10. **아카이브 준비**
    - [ ] 탐색 과정이 재현 가능한 형태로 기록됨
    - [ ] 다음 iteration에서 활용 가능한 인사이트가 정리됨

### 명시적 실패 조건 (이것만 피하면 됨)

- [ ] 증명 시도와 알려진 사실이 섞여 기록되지 않음
- [ ] 반례 점검이 생략되지 않음
- [ ] 근거 없이 "해결됨"으로 결론 내리지 않음
- [ ] 동일한 proof gap이 이유 없이 반복되지 않음
- [ ] 증명 공백을 숨기지 않음
