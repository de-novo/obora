## 2. 테스트 커버리지

### Unit Tests (93개)
- **ValidationService**: 입력 검증 로직 (정상, 에러, 엣지)
- **TaskService**: 비즈니스 로직 (CRUD, 진행률)
- **TaskRepository**: 데이터 CRUD (파일 I/O, 동시성)
- **Utils**: 포맷팅, ID 생성

### Integration Tests (20개)
- **FileLockManager**: 동시성 제어 (잠금 획득/해제, 타임아웃)
- **CLI Commands**: 명령어 실행 (add, list)

### E2E Tests (10개)
- **CLI 전체 흐름**: add → list → done → list
- **에러 처리**: 잘못된 입력, 존재하지 않는 ID
- **동시성**: 여러 프로세스에서 동시 실행
- **성능**: 1000개 태스크에서 200ms 이내 응답
