# Refined Idea: CLI 할 일 관리 도구 (Todo CLI)

작성일: 2026-03-20
Cycle: 1

---

## 1. 프로젝트 개요

### 제품명
**todo-cli** (임시)

### 목표
CLI 기반 할 일 관리 도구를 프로덕션 수준으로 구현하여, 작지만 완결된 소프트웨어를 하루 안에 자율적으로 완성할 수 있음을 검증한다.

### 핵심 가치
- **단순함**: 복잡한 기능 없이 핵심 기능에 집중
- **신뢰성**: 데이터 손실 없이 안전하게 저장
- **사용성**: 직관적인 CLI 인터페이스
- **품질**: 테스트 자동화와 명확한 에러 처리

### 기술 스택
- 언어: TypeScript
- 런타임: Node.js
- 패키지 매니저: npm
- 테스트: vitest
- 저장: 로컬 JSON 파일 (~/.todo-cli/todos.json)

---

## 2. 이번 Cycle에서 추가/개선할 기능

### Cycle 1 목표: 프로젝트 기초 및 핵심 CRUD 구현

#### 기능 1: CLI 기본 구조 및 할 일 추가 기능
- CLI 인터페이스 구축 (commander.js 사용)
- `todo add "<할 일 내용>"` 명령어 구현
- JSON 파일 저장소 초기화
- 기본 데이터 모델 정의

```
데이터 모델:
{
  "todos": [
    {
      "id": "uuid",
      "content": "할 일 내용",
      "completed": false,
      "createdAt": "2026-03-20T10:00:00Z",
      "updatedAt": "2026-03-20T10:00:00Z"
    }
  ]
}
```

#### 기능 2: 할 일 목록 조회 및 상태 관리
- `todo list` 명령어 구현 (미완료 항목 표시)
- `todo list --all` 모든 항목 표시
- `todo complete <id>` 완료 처리
- `todo delete <id>` 삭제 기능
