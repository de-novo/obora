## 2. 이번 Cycle (Cycle 2) 추가/개선할 기능

### 기능 1: 검색 기능 (Priority: HIGH)
**명령어:** `todo search <keyword> [options]`

**세부 사항:**
- 키워드 기반 할 일 검색 (대소문자 구분 없이)
- 옵션:
  - `--regex`: 정규표현식 검색 지원
  - `--case-sensitive`: 대소문자 구분
  - `--status=<pending|done>`: 상태 필터링과 결합

**프로덕션 품질 요구사항:**
- 빈 키워드 입력 시 적절한 에러 메시지
- 잘못된 정규표현식 문법에 대한 graceful 에러 처리
- 검색 결과 없음에 대한 명확한 사용자 피드백
- 0ms 이내 응답 (1000개 항목 기준)

### 기능 2: 통계 기능 (Priority: MEDIUM)
**명령어:** `todo stats`

**세부 사항:**
- 전체 할 일 개수
- 완료/미완료 개수 및 비율
- 오늘 추가된 항목 수
- 최근 7일 완료 추이 (선택적)

**프로덕션 품질 요구사항:**
- 빈 저장소에 대한 적절한 처리
- 숫자 포맷팅 (천 단위 구분자)
- 터미널 너비에 맞는 레이아웃 적응

## 3. 프로덕션 품질 기준

### 3.1 에러 핸들링
| 시나리오 | 처리 방식 | Exit Code |
|----------|-----------|-----------|
| 빈 검색어 | 사용자 안내 메시지 | 1 |
| 잘못된 정규식 | 에러 메시지 + 수정 제안 | 1 |
| 저장소 손상 | 자동 복구 시도 + 알림 | 2 |
| 권한 문제 | 명확한 권한 안내 | 2 |

### 3.2 엣지 케이스
- [ ] 빈 저장소에서 stats 실행
- [ ] 특수문자가 포함된 검색어
- [ ] 매우 긴 검색어 (1000자 이상)
- [ ] 유니코드/이모지가 포함된 할 일 내용 검색
- [ ] 동시 실행 시 데이터 무결성 (파일 락킹은 추후 고려)

### 3.3 UX 기준
- 일관된 출력 포맷 (색상, 정렬)
- `--json` 플래그로 JSON 출력 지원 (스크립트 연동용)
- `--quiet` 플래그로 최소 출력 모드
- 진행률 표시 (대용량 처리 시)
- 도움말 메시지 개선 (예제 포함)

### 3.4 코드 품질
- TypeScript strict mode 유지
- 새 기능별 최소 20개 테스트 케이스
- 함수당 단일 책임 원칙 준수
- JSDoc 주석 필수
