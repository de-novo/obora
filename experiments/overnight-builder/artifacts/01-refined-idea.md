# Refined Idea: CLI 기반 할 일 관리 도구 (todo-cli)

## 1. 프로젝트 개요

**제품명:** todo-cli

**목표:** Node.js/TypeScript 기반의 CLI 할 일 관리 도구로, 로컬 JSON 파일에 데이터를 저장하며, 프로덕션 수준의 품질로 구현한다.

**핵심 기능:**
- 할 일 추가 (add)
- 할 일 목록 조회 (list)
- 할 일 완료 처리 (complete)
- 할 일 삭제 (delete)

**기술 스택:**
- TypeScript
- Node.js
- Commander.js (CLI 프레임워크)
- Chalk (색상 출력)
- vitest (테스트)
- 로컬 JSON 파일 저장

---

## 2. 이번 Cycle에서 추가/개선할 기능 (Cycle 1)

이번은 첫 번째 cycle이므로 프로젝트 기반을 구축합니다.

### 기능 1: 프로젝트 초기화 및 핵심 할 일 관리 기능

**구현 범위:**
- `todo add <내용>` - 할 일 추가
- `todo list` - 할 일 목록 조회 (ID, 상태, 내용, 생성일)
- `todo complete <ID>` - 할 일 완료 처리
- `todo delete <ID>` - 할 일 삭제

**세부 사항:**
- JSON 파일(`~/.todo-cli/todos.json`)에 데이터 저장
- UUID 또는 timestamp 기반 고유 ID 생성
- 할 일 항목: `{ id, text, completed, createdAt, completedAt }`
- 목록 조회 시 미완료/완료 구분 표시

### 기능 2: 견고한 에러 핸들링 및 사용자 경험

**구현 범위:**
- 존재하지 않는 ID 입력 시 명확한 에러 메시지
- 빈 목록일 때 안내 메시지
- 잘못된 명령어 입력 시 도움말 표시
- 파일 읽기/쓰기 실패 시 복구 가능한 에러 처리

## 3. 프로덕션 품질 기준

### 3.1 에러 핸들링

| 시나리오 | 처리 방식 |
|---------|----------|
| JSON 파일 손상 | 자동으로 빈 파일로 초기화 + 사용자 알림 |
| 파일 권한 문제 | 명확한 에러 메시지 + 해결 방법 안내 |
| 존재하지 않는 ID | "ID {x}를 찾을 수 없습니다" 메시지 + 종료 코드 1 |
| 빈 텍스트 입력 | "할 일 내용을 입력해주세요" 메시지 |
| 잘못된 명령어 | 도움말 표시 + 사용 가능한 명령어 안내 |

### 3.2 엣지 케이스

- **빈 목록:** "아직 할 일이 없습니다. 'todo add <내용>'으로 추가하세요."
- **이미 완료된 항목 완료 시도:** "이미 완료된 항목입니다"
- **이미 삭제된 ID:** 삭제 전 존재 여부 확인
- **동시 실행:** 파일 lock은 고려하지 않으나, 데이터 손실 방지를 위해 atomic write 사용
- **특수 문자:** 할 일 텍스트에 따옴표, 이모지 등 포함 가능

### 3.3 UX 기준

- **색상 사용:** 완료된 항목은 회색/취소선, 미완료는 흰색, 에러는 빨간색
- **출력 포맷:** 테이블 형태 (ID | 상태 | 내용 | 생성일)
- **성공 피드백:** "✓ 할 일이 추가되었습니다 (ID: abc123)"
- **도움말:** `todo --help` 및 `todo <command> --help`

### 3.4 코드 품질

- TypeScript strict mode
- 모든 public 함수에 JSDoc 주석
- 핵심 로직 유닛 테스트 커버리지 80% 이상
- 일관된 코드 스타일 (ESLint/Prettier)
