## 6. 테스트 실행 방법

### 6.1 전체 테스트

```bash
npm test
```

### 6.2 특정 테스트

```bash
# 유닛 테스트만
npx vitest run unit/

# 통합 테스트만
npx vitest run integration/

# E2E 테스트만
npx vitest run e2e/

# 특정 파일
npx vitest run unit/todo.service.test.ts
```

### 6.3 커버리지 리포트

```bash

```

### 6.4 감시 모드

```bash

```
