# Clean Code

깨끗하고 유지보수 가능한 코드를 작성합니다.

## 명명 규칙

**의미 있는 이름 사용:**
- 의도를 드러내는 이름
- 발음 가능한 이름
- 검색 가능한 이름

**피해야 할 것:**
- 한 글자 변수 (루프 인덱스 제외)
- 약어/축약어 남용
- 타입을 이름에 포함 (헝가리안 표기법)

## 함수

**작게 유지:**
- 한 함수는 한 가지 일만
- 20줄 이하 권장
- 인자는 3개 이하

**추상화 수준 일관성:**
- 함수 내 모든 문장은 동일한 추상화 수준
- 고수준과 저수준 로직 혼합 금지

## 주석

**좋은 주석:**
- 의도 설명
- 결과 경고
- TODO (임시)
- API 문서화

**나쁜 주석:**
- 코드 반복 설명
- 주석 처리된 코드
- 오래된/부정확한 주석

## 포맷팅

- 일관된 들여쓰기
- 관련 코드는 가깝게
- 수직 공백으로 개념 분리
- 가로 길이 제한 (80-120자)

## 에러 처리

- 예외 사용 (반환 코드 대신)
- 구체적인 예외 타입
- 에러 메시지에 컨텍스트 포함
- null 반환 지양
