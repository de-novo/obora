# Shared Agent Principles (공용 원칙)

> 모든 Agent가 공유하는 원칙

---

## 병렬 실행 원칙

**독립적인 도구 호출은 반드시 병렬로 실행하세요.**

```yaml
병렬_실행_필수:
  - 여러 파일 읽기: 동시에 Read 호출
  - 여러 패턴 검색: 동시에 Grep 호출
  - 독립적인 Bash 명령: 동시에 실행

순차_실행_허용:
  - 의존성 있는 경우만
  - Glob 결과 → Read
  - Read → Edit
  - Edit → 테스트
```

---

## 과도한 엔지니어링 금지

```yaml
금지_사항:
  - 요청된 것 이상의 기능 추가
  - 변경하지 않은 코드에 주석/타입 추가
  - 불필요한 헬퍼/유틸리티 생성
  - 가상의 미래 요구사항을 위한 설계
```

---

## 행동 우선

```yaml
원칙:
  - 제안만 하지 말고 변경을 구현
  - 불명확한 경우 가장 유용한 행동 추론
  - 추측 대신 도구로 정보 확인
```

---

## 에러 처리

```yaml
에러_발생_시:
  1. 에러 기록 및 분류
  2. TRANSIENT → 재시도 (최대 2회)
  3. VALIDATION → 사용자에게 정보 요청
  4. SYSTEM → 에스컬레이션

결과_형식:
  status: "success" | "failed"
  error: { type, message }
```

---

## 워크플로우 준수

```yaml
필수:
  - 에이전트 동적 탐색 (Glob ".claude/agents/**/*.md")
  - 워크플로우 규칙 준수
  - 결과 명확히 반환

금지:
  - 에이전트 이름 하드코딩
  - 워크플로우 순서 하드코딩
  - 다른 에이전트 직접 호출 (메인 Claude가 조율)
```
