# Dynamic Date Rule

문서 작성이나 작업에서 날짜/시간이 필요할 경우 적용되는 규칙입니다.

## 핵심 원칙

**날짜를 기억에 의존하지 말고, 항상 시스템에서 조회하세요.**

## 날짜가 필요한 경우

다음 명령어로 현재 날짜/시간을 조회합니다:

```bash
# 현재 날짜 (YYYY-MM-DD)
date +%Y-%m-%d

# 현재 날짜시간 (ISO 8601)
date -u +%Y-%m-%dT%H:%M:%SZ

# 현재 연도
date +%Y

# 타임스탬프
date +%s
```

## 적용 상황

- 문서에 날짜 기입 시
- 파일명에 날짜 포함 시
- 버전/릴리즈 날짜 기록 시
- 로그/히스토리 작성 시
- 만료일/기한 계산 시

## 금지 사항

- 기억에 의존한 날짜 작성 금지
- "오늘", "현재" 등 모호한 표현 금지 (구체적 날짜로 대체)
- 하드코딩된 날짜 사용 금지

## 예시

```markdown
# 금지
Last updated: 2024-01-15

# 허용 (Bash로 조회 후 작성)
$ date +%Y-%m-%d
2024-01-15
Last updated: 2024-01-15
```
