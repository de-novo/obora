# DRY, KISS, YAGNI

코드 작성 시 준수해야 할 핵심 원칙들입니다.

## DRY - Don't Repeat Yourself

동일한 코드를 반복하지 않습니다.

**적용:**
- 중복 코드는 함수/모듈로 추출
- 설정값은 상수로 정의
- 공통 로직은 유틸리티로 분리

**주의:**
- 우연히 비슷한 코드는 DRY 대상 아님
- 과도한 추상화는 오히려 복잡성 증가
- 2-3번 반복 후 추출 고려 (Rule of Three)

## KISS - Keep It Simple, Stupid

단순하게 유지합니다.

**적용:**
- 가장 간단한 해결책 선택
- 복잡한 로직은 단순한 단계로 분해
- 명확하고 읽기 쉬운 코드 작성

**위반 신호:**
- 설명 없이 이해하기 어려운 코드
- 과도한 추상화 레이어
- 불필요한 최적화

## YAGNI - You Ain't Gonna Need It

필요하지 않은 기능을 미리 구현하지 않습니다.

**적용:**
- 현재 요구사항만 구현
- "나중에 필요할 것 같은" 기능 구현 금지
- 확장 가능성은 설계로, 구현은 최소로

**예외:**
- 명확히 예정된 기능
- 아키텍처 수준의 확장성
