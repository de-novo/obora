# No Auto Build

빌드는 사용자의 명시적 요청이 있을 때만 수행합니다.

## 핵심 원칙

**빌드 명령 자동 실행 금지**: 코드 변경 후 자동으로 빌드를 실행하지 않습니다.

## 이유

- **Dev 서버 중단**: Next.js, Vite 등 프레임워크에서 빌드 실행 시 dev 서버 재시작 필요
- **불필요한 대기 시간**: 개발 중에는 HMR(Hot Module Replacement)로 충분
- **리소스 낭비**: 중간 단계에서 프로덕션 빌드는 불필요

## 금지 사항

### 자동 빌드 실행

```bash
# 금지 - 코드 변경 후 자동 실행
pnpm build
npm run build
yarn build
next build
```

### 암묵적 빌드 트리거

```bash
# 금지 - 검증 목적으로 빌드 실행
"타입 검사를 위해 빌드를 실행하겠습니다"
"변경사항 확인을 위해 빌드합니다"
```

## 허용되는 경우

### 사용자 명시적 요청

```yaml
허용_트리거:
  - "빌드해줘"
  - "build 실행해"
  - "프로덕션 빌드 해줘"
  - "빌드 오류 확인해줘"
  - 커밋/배포 전 명시적 빌드 요청
```

### 타입 검사는 별도 명령

```bash
# Good - 빌드 없이 타입 검사
pnpm tsc --noEmit
npx tsc --noEmit

# Bad - 빌드로 타입 검사
pnpm build
```

### 린트 검사는 별도 명령

```bash
# Good - 빌드 없이 린트
pnpm lint
npm run lint

# Bad - 빌드로 린트 검사
pnpm build
```

## 대안

| 목적 | 사용할 명령 |
|------|-------------|
| 타입 검사 | `tsc --noEmit` |
| 린트 검사 | `eslint .` 또는 `pnpm lint` |
| 테스트 | `pnpm test` |
| 변경 확인 | Dev 서버의 HMR 활용 |

## 요약

```yaml
원칙:
  - 빌드는 명시적 요청 시에만 실행
  - 타입/린트 검사는 전용 명령 사용
  - Dev 환경에서는 HMR 활용

금지:
  - 코드 변경 후 자동 빌드
  - 검증 목적 빌드
  - 암묵적 빌드 트리거

허용:
  - 사용자 명시적 빌드 요청
  - 배포/커밋 전 명시적 요청
```
