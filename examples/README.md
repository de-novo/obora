# Examples

This folder contains runnable workflow samples used by M5 Public Release:

- `01-simple-pipeline/` — minimal deterministic pipeline with policy and recovery
- `02-multi-agent-consensus/` — consensus gate and discussion pattern
- `03-policy-gate/` — explicit policy gate workflow
- `04-plugin-custom/` — custom plugin pattern usage
- `05-dashboard-monitoring/` — dashboard + monitoring oriented flow
- `hello-obora.yaml` — minimal top-level quick-run sample

Supporting files:
- `config.yaml`
- `policy.yaml`
