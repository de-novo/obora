```
┌─────────────────────────────────────────────────────────────────────┐

│                          │    Delete task?                │         │

│                          │                                 │         │

│                          │    [Cancel]    [Delete]         │         │

└─────────────────────────────────────────────────────────────────────┘
```

**다이얼로그 명세:**
- 트리거: 삭제 버튼 클릭

- ARIA: role="dialog", aria-modal="true", aria-labelledby="dialog-title"

## 3. 컴포넌트별 상세 와이어프레임 (Component Detail Wireframes)

### 3.1 AddTodo Component

```
┌─────────────────────────────────────────────────────────────────────┐
│  <form role="group" aria-label="Add new task">                       │
│  ┌───┐ ┌─────────────────────────────────────────┐ ┌─────────────┐  │
│  │ + │ │ Add a new task                          │ │  Add Task   │  │
│  └───┘ │  (placeholder text)                     │ │   Button    │  │
│        └─────────────────────────────────────────┘ └─────────────┘  │
│    icon                    input field               button       │
│  └─────────────────────────────────────────────────────────────────┘  │
│  <label for="todo-input">What needs to be done?</label> (visible)     │
│  <input id="todo-input" type="text" placeholder="Add a new task">     │
│  └─────────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

**요소 명세:**

| 요소 | 타입 | 크기 | 상태 | ARIA |
|------|------|------|------|------|
| 레이블 | label | - | visible | for="todo-input" (A11Y-P2-005 수정) |
| 아이콘 버튼 (+) | button | 44px × 44px | enabled/disabled | aria-label="Add task" |
| 입력 필드 | input | width: auto, height: 44px | focus/blur/error | (aria-label 제거 - visible label 사용) |
| 추가 버튼 | button | min-width: 100px, height: 44px | enabled/disabled | aria-label="Add task" |
| 컨테이너 | form | - | - | role="group", aria-label="Add new task" (A11Y-P2-006 수정) |

**상태 전환:**

| 상태 | 설명 | 시각적 표시 |
|------|------|-------------|
| Default | 초기 상태 | placeholder 표시 |
| Focus | 입력 필드 포커스 | 파란 테두리 (#3B82F6, 대비비 4.52:1) |
| Typing | 입력 중 | 텍스트 표시 |
| Error | 검증 실패 | 빨간 테두리 (#991B1B) + 에러 메시지 |
| Disabled | 저장 중 | 버튼 비활성화 |

## 6. 포커스 순서 (Focus Order)

### 6.1 Tab Navigation Flow

```
1. 레이블 (What needs to be done?) - tabindex="-1" (선택 불가)
2. 입력 필드 (AddTodo input) - tabindex="0"
         ↓ [Tab]
3. 추가 버튼 (AddTodo button) - tabindex="0"
         ↓ [Tab]
4. 첫 번째 태스크 토글 (TodoItem checkbox) - tabindex="0"
         ↓ [Tab]
5. 첫 번째 태스크 삭제 (TodoItem delete) - tabindex="0"
         ↓ [Tab]
6. 두 번째 태스크 토글 - tabindex="0"
         ↓ [Tab]
7. 두 번째 태스크 삭제 - tabindex="0"
... (반복)
         ↓ [Tab]
N. All 필터 버튼 - tabindex="0"
         ↓ [Tab]
N+1. Active 필터 버튼 - tabindex="0"
         ↓ [Tab]
N+2. Completed 필터 버튼 - tabindex="0"
         ↓ [Tab]
1. (처음으로 순환)

[Delete Confirm Dialog 열린 시]
└─▶ Delete 버튼 → Cancel 버튼 → Delete 버튼 (순환)
```

## 8. 접근성 와이어프레임 고려사항 (Accessibility Considerations)

### 8.1 키보드 접근성

| 기능 | 키 조합 | 동작 | 포커스 이동 |
|------|----------|------|------------|
| 입력 필드 포커스 | Tab | 입력 필드로 포커스 | 첫 번째 포커스 가능 요소 |
| 태스크 추가 | Enter | 빈 입력 시 에러, 유효 시 추가 | 입력 필드 유지 |
| 태스크 토글 | **Space** (A11Y-P2-003) | 완료 상태 변경 | toggle 버튼 유지 |
| 태스크 삭제 | Enter | 삭제 확인 다이얼로그 표시 (A11Y-P1-006) | 모달 Delete 버튼 |
| 다이얼로그 닫기 | Escape | 다이얼로그 닫기 | 삭제 버튼으로 복귀 |
| 필터 변경 | **Space** (A11Y-P2-003) | 필터 전환 | 해당 버튼 유지 |
| 페이지 이동 | Tab/Shift+Tab | 순방향/역방향 이동 | 다음/이전 요소 |

### 8.2 스크린 리더 지원

|------|-----------|------------------|

| TodoList | role="list", aria-live="polite" | "List, 3 items" |
| TodoItem | role="listitem", role="group" | "Task: [텍스트], list item" |
