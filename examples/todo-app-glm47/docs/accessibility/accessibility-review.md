# 접근성 리뷰 (Accessibility Review)
**작성일자:** 2026-03-02
**기반 문서:** UI 와이어프레임 (`docs/ui/ui-wireframe.md`), 인터랙션 스펙 (`docs/ui/interaction-spec.md`)
**기준:** WCAG 2.1 Level AA

## 개요

이 문서는 통합 생산성 플랫폼의 UI 설계를 WCAG 2.1 Level AA 관점에서 리뷰하고, 발견된 접근성 결함과 수정 권장사항을 정의합니다.

## 1. 인식 (Perceivable)

### 1.1 색상만으로 정보 전달 (WCAG 2.1.1 - Level A)

| 화면 | 문제 | 현재 설계 | 수정 권장 |
|------|------|-----------|-----------|
| 목록 화면 | 우선순위를 색상(🔴 높음/🟡 중간/🟢 낮음)만으로 표시 | 색상만 구분 | 아이콘 옆 텍스트 라벨 추가 ("높음", "중간", "낮음") |
| 목록 화면 | 완료 상태를 취소선만으로 표시 | 텍스트에 취소선만 | "완료" 라벨 또는 체크 아이콘 추가 |
| 캘린더 | 오늘 날짜를 박스 둥근 테두리만으로 표시 | 시각적 테두리만 | "오늘" 텍스트 라벨 추가 |
| 에러 상태 | 에러 유형을 색상만으로 구분 (빨강/파랑/노랑) | 색상만 구분 | 아이콘 + 텍스트로 에러 유형 명시 |
| 프로그레스 바 | 진척률을 색상만으로 표시 | 색상만 | 백분율 텍스트 추가 (예: "65% 완료") |

### 1.2 텍스트 대비 (WCAG 1.4.3 - Level AA)

| 컴포넌트 | 문제 | 현재 설계 | 수정 권장 |
|----------|------|-----------|-----------|
| 회색 플레이스홀더 | 플레이스홀더 텍스트가 너무 연할 수 있음 | 추정 #9CA3AF (회색) | 대비비 4.5:1 이상 확보, #6B7280 이상 권장 |
| 비활성 버튼 | 비활성 상태 텍스트 #9CA3AF | 대비비 낮음 | #52525B 이상으로 대비 개선 |
| 경고/에러 토스트 | 노랑/빨강 배경에 흰색 텍스트 | 대비비 충분 여부 확인 | #F59E0B/흰색 대비 3.9:1 (부족) → #D97706 배경으로 변경 |

### 1.3 이미지 텍스트 (WCAG 1.4.5 - Level AA)

| 화면 | 문제 | 현재 설계 | 수정 권장 |
|------|------|-----------|-----------|
| 이모지 아이콘 | ✉️📅📝🎯 등 이모지가 정보 전달용으로 사용됨 | 이모지만으로 의미 전달 | 모든 정보성 이모지에 `aria-label` 추가, 대체 텍스트 제공 |

### 1.4 재정의 가능 (WCAG 1.4.4 - Level AA)

| 화면 | 문제 | 현재 설계 | 수정 권장 |
|------|------|-----------|-----------|
| 목록 아이템 | 가로 스크롤 탭 (인박스/프로젝트)에 높이 제한 | 200% 확대 시 스크롤 필요 | 수직 레이아웃 옵션 제공, 세로 스와이프 지원 |

## 2. 운용 (Operable)

### 2.1 키보드 접근성 (WCAG 2.1.1 - Level A)

| 컴포넌트 | 문제 | 현재 설계 | 수정 권장 |
|----------|------|-----------|-----------|
| FAB | 드래그 가능 여부 불명확 | FAB 위치 | FAB에 `tabindex="0"`, Enter/Space로 동작하도록 구현 |
| 스와이프 액션 | 왼→오/오→완 스와이프가 터치 전용 | 터치만 | 키보드 단축키 제공 (완료: C, 삭제: Delete) |
| 풀 투 리프레시 | 터치 제스처만 | 터치만 | R 단축키로 새로고침 지원 |
| 길게 누르기 | 진동 피드백만 | 진동만 | Shift+Enter로 길게 누르기 동작 대체 제공 |
| 드래그 앤 드롭 (정렬) | 마우스/터치 전용 | 드래그만 | ↑↓ 방향키로 순서 변경 지원 |

### 2.2 초점 표시 (WCAG 2.4.7 - Level AA)

| 컴포넌트 | 문제 | 현재 설계 | 수정 권장 |
|----------|------|-----------|-----------|
| 모든 인터랙티브 요소 | 초점 표시 스타일 미정의 | - | outline: 3px solid #3B82F6, offset: 2px 기본 스타일 정의 |
| 체크박스 | 커스텀 체크박스 사용 가능성 | - | 초점 상태에서 시각적 피드백 추가 |
| 캘린더 날짜 | 선택 날짜 초점 표시 필요 | 파란색 배경만 | 초점 시 테두리 추가 (예: 2px 흰색 테두리) |

### 2.3 타이머 (WCAG 2.2.1 - Level A)

| 컴포넌트 | 문제 | 현재 설계 | 수정 권장 |
|----------|------|-----------|-----------|
| 자동 저장 (30초) | 타이머가 켜져 있음 | 사용자에게 알림 없음 | 저장 전 5초 경고 토스트, 자동 저장 끄기 옵션 제공 |
| 토스트 자동 닫기 | 성공(3s), 정보(4s), 경고(5s), 에러(6s) | 타이머로 닫힘 | 마우스 호버/키보드 초점 시 타이머 일시 정지, 수동 닫기 버튼 제공 |

### 2.4 초점 이동 (WCAG 2.4.3 - Level A)

| 화면 | 문제 | 현재 설계 | 수정 권장 |
|------|------|-----------|-----------|
| 모달/다이얼로그 | 초점 트랩 여부 미정의 | - | 열릴 때 초점을 모달 내부로, 닫힐 때 호출자로 복구 |
| Command Palette | ESC로 닫기만 명시 | ESC만 | ESC 닫기, 방향키로 탐색, Enter로 선택 |

### 2.5 포인터 제스처 (WCAG 2.5.1 - Level A)

| 제스처 | 문제 | 수정 권장 |
|--------|------|-----------|
| 스와이프 (왼→오 완료) | 단일 손가락 제스처 | 길게 누른 후 방향키로 대체 |
| 길게 누르기 | 시간 기반 제스처 | Shift+Enter로 대체 |
| 풀 투 리프레시 | 드래그 제스처 | R 단축키로 대체 |

## 3. 이해 (Understandable)

### 3.1 페이지 언어 (WCAG 3.1.1 - Level A)

| 문제 | 현재 설계 | 수정 권장 |
|------|-----------|-----------|
| HTML `lang` 속성 미지정 | - | `<html lang="ko">` 지정 |

### 3.2 입력 에러 식별 (WCAG 3.3.1 - Level A)

| 필드 | 문제 | 현재 설계 | 수정 권장 |
|------|------|-----------|-----------|
| 모든 유효성 검증 | 에러 메시지 위치 연관성 불명확 | 입력창 아래 빨간 텍스트 | `aria-describedby`로 에러 메시지와 연결 |
| 작업 제목 | "제목을 입력해주세요" 메시지만 | - | 에러 메시지에 `role="alert"` 추가, 스크린 리더에서 즉시 읽히도록 |

### 3.3 라벨 (WCAG 3.3.2 - Level A)

| 필드 | 문제 | 현재 설계 | 수정 권장 |
|------|------|-----------|-----------|
| 플레이스홀더만 있는 입력 | 플레이스홀더를 라벨로 사용 | "제목", "설명" 플레이스홀더 | 별도 `<label>` 요소 추가, `aria-label` 제공 |
| 아이콘 버튼 | [+ 작업 추가] | 텍스트 없음 | `aria-label="새 작업 추가"` 추가 |
| 검색 아이콘 | 🔍 | 텍스트 없음 | `aria-label="검색"` 추가 |
| 체크박스 | 완료 체크박스 | 시각적 체크박스 | `aria-label="완료"` 추가 |

### 3.4 일관성 (WCAG 3.2.4 - Level AA)

| 문제 | 수정 권장 |
|------|-----------|
| "완료" 버튼이 작업 상세에서는 우측 상단, 입력 화면에서는 저장 버튼임 | 완료 동작의 버튼 라벨/위치 일관화 |
| 스와이프 방향이 왼→오 완료(녹색), 오→완 삭제(빨강)로 복합적 | 사용자 설정 가능하도록 옵션 제공 |

## 4. 견고 (Robust)

### 4.1 마크업 유효성 (WCAG 4.1.1 - Level A)

| 문제 | 현재 설계 | 수정 권장 |
|------|-----------|-----------|
| 의미적 구조 미정의 | - | `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>` 사용 |
| 리스트 아이템이 `<div>`로 구현 가능성 | - | `<ul>`/`<ol>`, `<li>` 사용 |

### 4.2 이름, 역할, 값 (WCAG 4.1.2 - Level A)

| 컴포넌트 | 문제 | 수정 권장 |
|----------|------|-----------|
| 모든 인터랙티브 요소 | `role`, `aria-label` 미정의 | - | 모든 버튼/링크에 `aria-label` 추가 |
| 체크박스 | 커스텀 체크박스 | - | `role="checkbox"`, `aria-checked` 속성 추가 |
| 스위치 토글 | 상태 표시 불명확 | - | `role="switch"`, `aria-checked` 추가 |
| 드롭다운 | 역할 미정의 | - | `role="listbox"`, `aria-expanded` 추가 |
| 탭 | 서브탭 구조 | - | `role="tablist"`, `role="tab"`, `aria-selected` 추가 |
| 모달 | 역할 미정의 | - | `role="dialog"`, `aria-modal="true"` 추가 |

### 4.3 동적 콘텐츠 알림 (WCAG 4.1.3 - Level AA)

| 상황 | 문제 | 수정 권장 |
|------|------|-----------|
| 목록 로딩 완료 | 콘텐츠가 갱신됨을 알리지 않음 | - | `aria-live="polite"`로 로딩 완료 알림 |
| 에러 발생 | 토스트로만 표시 | - | `role="alert"`, `aria-live="assertive"`로 에러 알림 |
| 저장 성공 | 토스트로만 표시 | - | `aria-live="polite"`로 성공 알림 |

## 7. 수정 체크리스트

### 7.1 마크업 (Markup)

- [ ] `<html lang="ko">` 지정
- [ ] 의미적 태그 사용 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- [ ] 리스트 아이템을 `<ul>`/`<ol>`, `<li>`로 구현
- [ ] 모든 버튼/링크에 `aria-label` 추가
- [ ] 체크박스에 `role="checkbox"`, `aria-checked` 추가
- [ ] 스위치 토글에 `role="switch"`, `aria-checked` 추가
- [ ] 드롭다운에 `role="listbox"`, `aria-expanded` 추가
- [ ] 탭에 `role="tablist"`, `role="tab"`, `aria-selected` 추가
- [ ] 모달에 `role="dialog"`, `aria-modal="true"` 추가

### 7.2 키보드 (Keyboard)

- [ ] 모든 인터랙티브 요소에 `tabindex="0"` 설정 (필요 시)
- [ ] Enter/Space로 버튼 동작
- [ ] 방향키로 리스트/캘린더 탐색
- [ ] ESC로 모달/Command Palette 닫기
- [ ] 초점 표시 스타일 정의 (outline: 3px solid #3B82F6)
- [ ] 스와이프 동작 키보드 단축키 대체 (완료: C, 삭제: Delete)
- [ ] 풀 투 리프레시 R 단축키 대체
- [ ] 길게 누르기 Shift+Enter 대체

### 7.3 색상/대비 (Color/Contrast)

- [ ] 우선순위 색상에 텍스트 라벨 추가
- [ ] 완료 상태에 "완료" 라벨 추가
- [ ] 오늘 날짜에 "오늘" 텍스트 추가
- [ ] 플레이스홀더 텍스트 대비 4.5:1 이상
- [ ] 비활성 버튼 텍스트 대비 4.5:1 이상
- [ ] 경고/에러 토스트 배경색 대비 개선

### 7.4 라벨 (Labels)

- [ ] 모든 입력 필드에 `<label>` 요소 추가
- [ ] 플레이스홀더를 라벨로 사용하지 않음
- [ ] 아이콘 버튼에 `aria-label` 추가
- [ ] 에러 메시지에 `aria-describedby` 연결

### 7.5 동적 콘텐츠 (Dynamic Content)

- [ ] 로딩 완료 시 `aria-live="polite"` 알림
- [ ] 에러 발생 시 `role="alert"`, `aria-live="assertive"` 알림
- [ ] 토스트/스낵바에 수동 닫기 버튼 제공
- [ ] 토스트 자동 닫기 시 초점/호버 시 타이머 일시 정지

### 7.6 텍스트 (Text)

- [ ] 기본 텍스트 크기 18px 이상
- [ ] 200% 확대 지원
- [ ] 줄 높이 최소 1.5배
- [ ] 단락 간격 최소 2배

## 9. 결론

총 **22건의 접근성 결함**이 발견되었습니다. 이 중 **5건**은 P1 (필수 수정), **5건**은 P2 (권장 수정), **3건**은 P3 (개선 권장)으로 분류되었습니다.

### 우선 수정 항목 (P1)

1. 모든 인터랙티브 요소에 키보드 접근 제공
2. 모든 버튼, 체크박스, 스위치에 `role` 및 `aria-label` 추가
3. 모달/다이얼로그에 초점 트랩 구현
4. 플레이스홀더 대신 `<label>` 요소 사용
5. 의미적 HTML 구조 사용

이 문서는 WCAG 2.1 Level AA 준수를 위한 기준이며, 개발 단계에서 이 결함들을 해결하고 정기적으로 접근성 테스트를 수행해야 합니다.
