# UI 와이어프레임 문서
**작성일자:** 2026-03-02
**기반 문서:** UX 전략 (`docs/ux/ux-strategy.md`)

---

## 개요

이 문서는 통합 생산성 플랫폼의 핵심 화면 와이어프레임을 정의합니다. 다음 4가지 화면을 포함합니다:

1. **목록 화면** - 작업/이벤트/노트의 리스트 뷰
2. **상세 화면** - 단일 아이템의 상세 정보 및 편집
3. **필터 화면** - 검색, 필터, 정렬 옵션
4. **입력 화면** - 새 아이템 생성 및 편집 폼

## 6. 공통 컴포넌트 가이드

### 6.1 버튼

| 타입 | 스타일 | 용도 |
|------|--------|------|
| Primary | 파란색 배경, 흰색 텍스트 | 주요 작업 (저장, 생성) |
| Secondary | 회색 배경, 흰색 텍스트 | 보조 작업 (취소) |
| Text | 텍스트만 | 링크, 부가 작업 |
| FAB | 원형, 파란색 | 빠른 생성 |

### 6.2 입력 필드

| 타입 | 스타일 | 레이블 |
|------|--------|--------|
| Text | 박스, 하단 테두리 | 제목, 검색 |
| Textarea | 박스, 하단 테두리 | 설명, 내용 |
| Select | 드롭다운 | 드롭다운 선택 |
| Date | 날짜 선택기 | 마감일 |
| Time | 시간 선택기 | 시간 |

### 6.3 아이콘

| 아이콘 | 의미 |
|--------|------|
| ☰ | 메뉴 |
| 🔍 | 검색 |

| ← | 뒤로가기 |
| ✓ | 완료/수락 |
| ✕ | 닫기/취소 |
| 📅 | 날짜 |
| ⏰ | 시간 |
| 📍 | 위치 |
| 🏷️ | 태그 |
