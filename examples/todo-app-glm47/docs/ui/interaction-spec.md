## 상태전이

### 1. 엔티티별 상태전이

#### 1.1 작업 (Task)

| 현재 상태 | 이벤트 | 다음 상태 | 인터랙션 |
|-----------|--------|-----------|----------|
| `todo` | 시작 버튼 클릭 | `in_progress` | 버튼 아이콘 ▶ → ⏸, 배경색 파란색으로 변경 |
| `todo` | 완료 체크박스 클릭 | `done` | 체크박스 체크, 텍스트 취소선, 페이드 아웃 후 리스트 하단으로 이동 |
| `in_progress` | 일시정지 버튼 클릭 | `todo` | 버튼 아이콘 ⏸ → ▶, 배경색 회색으로 복원 |
| `in_progress` | 완료 체크박스 클릭 | `done` | 체크박스 체크, 텍스트 취소선, 완료 애니메이션 |
| `done` | 완료 체크박스 클릭 | `todo` | 체크박스 해제, 취소선 제거, 리스트 상단으로 이동 |
| `done` | 삭제 버튼 클릭 | `deleted` | 스와이프/삭제 아이콘 클릭 → 확인 다이얼로그 → 삭제 애니메이션 |
| 모든 상태 | 마감일 초과 | `overdue` | 마감일 배지 빨간색으로 변경, 알림 표시 |

#### 1.2 이벤트 (Event)

| 현재 상태 | 이벤트 | 다음 상태 | 인터랙션 |
|-----------|--------|-----------|----------|
| `upcoming` | 현재 시간 도달 | `ongoing` | 캘린더에서 해당 시간 강조 표시, 알림 토스트 |
| `ongoing` | 종료 시간 도달 | `completed` | 상태 배지 색상 변경, 완료 체크 표시 |
| `upcoming` | 취소 버튼 클릭 | `cancelled` | 취소선 표시, 회색 처리 |
| `cancelled` | 복원 버튼 클릭 | `upcoming` | 취소선 제거, 원래 색상 복원 |
| `completed` | 삭제 버튼 클릭 | `deleted` | 확인 다이얼로그 → 삭제 애니메이션 |

#### 1.3 노트 (Note)

| 현재 상태 | 이벤트 | 다음 상태 | 인터랙션 |
|-----------|--------|-----------|----------|
| `draft` | 저장 버튼 클릭 | `saved` | 저장 성공 토스트, 수정일 타임스탬프 업데이트 |
| `draft` | 자동 저장 트리거 (30초) | `saved` | "저장됨" 인디케이터 표시 |
| `saved` | 편집 시작 | `editing` | 수정 인디케이터 표시, 자동 저장 타이머 시작 |
| `editing` | 저장 버튼 클릭 | `saved` | 저장 성공 토스트 |
| `editing` | 30초 동안 변경 없음 | `saved` | 자동 저장, "자동 저장됨" 토스트 |
| 모든 상태 | 삭제 버튼 클릭 | `deleted` | 스와이프/삭제 아이콘 → 확인 다이얼로그 → 삭제 애니메이션 |

#### 1.4 목표 (Goal)

| 현재 상태 | 이벤트 | 다음 상태 | 인터랙션 |
|-----------|--------|-----------|----------|
| `not_started` | 시작 버튼 클릭 | `in_progress` | 프로그레스 바 활성화, 진행률 0%로 초기화 |
| `in_progress` | 진행률 100% 도달 | `achieved` | 프로그레스 바 완전 채우기, 축하 애니메이션 (confetti) |
| `achieved` | 재설정 버튼 클릭 | `not_started` | 프로그레스 바 초기화, 진행률 0% |
| `not_started` | 종료일 지남 | `expired` | 종료일 배지 빨간색, "기한 만료" 메시지 |
| `in_progress` | 종료일 지남 | `expired` | 프로그레스 바 빨간색 표시 |

### 2. 네비게이션 상태전이

#### 2.1 탭 전환

| 현재 탭 | 대상 탭 | 인터랙션 |
|---------|---------|----------|
| 인박스 | 프로젝트 | 인박스 콘텐츠 슬라이드 아웃 → 프로젝트 콘텐츠 슬라이드 인 (300ms) |
| 작업 | 캘린더 | 작업 리스트 페이드 아웃 → 캘린더 페이드 인 (250ms) |
| 노트 | 목표 | 노트 카드 그리드 축소 → 목표 리스트 확장 (300ms) |

#### 2.2 목록 ↔ 상세 전환

| 방향 | 인터랙션 |
|------|----------|
| 목록 → 상세 | 아이템 클릭 → 상세 화면 슬라이드 업 (iOS) / 페이드 인 (Android) |
| 상세 → 목록 | 백 버튼 / 스와이프 다운 → 상세 화면 슬라이드 다운 / 페이드 아웃 |

## 로딩 상태

### 1. 로딩 타입별 인터랙션

#### 1.1 초기 로딩 (App Launch)

| 화면 | 로딩 인디케이터 | 타이머 | 대체 동작 |
|------|-----------------|--------|-----------|
| 스플래시 | 앱 로고 + 로딩 스피너 (중앙) | 최대 3초 | 로고 패닝 애니메이션 |
| 데이터 동기화 중 | 로딩 스피너 + "데이터 동기화 중..." 텍스트 | 최대 5초 | 오프라인 모드 안내 버튼 노출 |

#### 1.2 목록 로딩

| 화면 | 로딩 인디케이터 | 위치 | 스켈레톤 UI |
|------|-----------------|------|-------------|
| 작업 목록 | 로딩 스피너 (중앙) | 리스트 영역 상단 | 3개 아이템 스켈레톤 |
| 캘린더 | 로딩 스피너 (월 헤더) | 캘린더 헤더 | 월 그리드 스켈레톤 |
| 노트 목록 | 로딩 스피너 (중앙) | 그리드 영역 | 4개 카드 스켈레톤 |
| 목표 목록 | 로딩 스피너 (중앙) | 리스트 영역 | 2개 아이템 스켈레톤 |

**스켈레톤 UI 스펙:**
- 배경색: `#F0F0F0`
- 애니메이션: 쉬머 (왼→오, 1.5s, ease-in-out)
- 높이: 각 엔티티별 실제 아이템 높이와 동일

#### 1.3 상세 로딩

| 화면 | 로딩 인디케이터 | 위치 |
|------|-----------------|------|
| 작업 상세 | 프로그레스 바 (상단) | 화면 상단, 너비 100% |
| 노트 상세 | 로딩 스피너 (중앙) | 에디터 영역 |
| 이벤트 상세 | 로딩 스피너 (중앙) | 콘텐츠 영역 |
| 목표 상세 | 프로그레스 바 (상단) | 화면 상단, 너비 100% |

#### 1.4 작업 로딩 (Action Loading)

| 작업 | 로딩 인디케이터 | 위치 |
|------|-----------------|------|
| 저장 | 버튼 내 스피너 | 버튼 텍스트 대체 |
| 삭제 | 버튼 내 스피너 | 버튼 텍스트 대체 |
| 검색 | 검색창 내 스피너 | 검색창 오른쪽 |
| 필터 적용 | 스크린 오버레이 스피너 | 화면 중앙 |

### 2. 로딩 시간별 동작

| 시간 | 동작 |
|------|------|
| < 200ms | 로딩 인디케이션 없음 (즉시 표시) |
| 200ms ~ 500ms | 로딩 스피너 표시 |
| 500ms ~ 2s | 스켈레톤 UI 표시 |
| > 2s | "로딩 중입니다. 잠시만 기다려주세요." 텍스트 추가 |
| > 5s | "다시 시도" 버튼 노출 (네트워크 에러 가능성) |
| > 10s | 타임아웃 에러 처리 |

## 에러 상태

### 1. 에러 타입별 인터랙션

#### 1.1 네트워크 에러

| 상황 | 아이콘 | 제목 | 설명 | 버튼 |
|------|--------|------|------|------|
| 오프라인 | 📶 | "네트워크 연결 없음" | "인터넷 연결을 확인하고 다시 시도하세요." | "다시 시도" |
| API 실패 | ⚠️ | "데이터를 불러올 수 없습니다" | "서버 연결에 실패했습니다. 다시 시도해주세요." | "다시 시도" |
| 타임아웃 | ⏱️ | "요청 시간 초과" | "요청이 너무 오래 걸립니다. 다시 시도해주세요." | "다시 시도" |

**인터랙션:**
- 스낅바/토스트로 표시 (하단)
- 자동 재시도 3회 (1초 간격)
- 실패 시 에러 화면 표시

#### 1.2 유효성 검증 에러

| 필드 | 에러 상황 | 에러 메시지 | 인터랙션 |
|------|----------|-------------|----------|
| 작업 제목 | 빈 값 | "제목을 입력해주세요" | 입력창 아래 빨간 텍스트, 입력창 테두리 빨간색 |
| 작업 제목 | 100자 초과 | "제목은 100자 이내로 입력해주세요" | 동일 |
| 마감일 | 과거 날짜 | "마감일은 오늘 이후로 설정해주세요" | 입력창 아래 빨간 텍스트 |
| 이메일 | 형식 오류 | "올바른 이메일 주소를 입력해주세요" | 입력창 아래 빨간 텍스트 |
| 전화번호 | 형식 오류 | "올바른 전화번호를 입력해주세요" | 입력창 아래 빨간 텍스트 |

**인터랙션:**
- 실시간 검증 (blur 또는 입력 후 500ms)
- 에러 상태 시 저장 버튼 비활성화

#### 1.3 권한 에러

| 수정 불가 | 📝 | "수정 권한이 없습니다" | "이 항목은 읽기 전용입니다." | "확인" |
| 삭제 불가 | 🗑️ | "삭제 권한이 없습니다" | "이 항목을 삭제할 권한이 없습니다." | "확인" |

#### 1.4 저장 실패

| 상황 | 아이콘 | 제목 | 설명 | 버튼 |
|------|--------|------|------|------|
| 저장 실패 | 💾 | "저장에 실패했습니다" | "네트워크 연결을 확인하고 다시 시도하세요." | "다시 시도" |

## 공통 인터랙션 패턴

### 1. 터치 피드백

| 요소 | 정상 상태 | 누름 상태 | 활성 상태 | 비활성 상태 |

| 버튼 | 기본 색상 | 색상 어둡게 (10%) | 기본 색상 | #E5E7EB, 텍스트 #9CA3AF |
| 리스트 아이템 | 배경 #FFFFFF | 배경 #F3F4F6 | 배경 #FFFFFF | 배경 #F9FAFB |
| 아이콘 버튼 | 기본 색상 | 배경 #F3F4F6 | 기본 색상 | #D1D5DB |
| FAB | 기본 색상 | 크기 축소 (5%) | 기본 색상 | #E5E7EB |

### 2. 스와이프 액션

| 방향 | 아이템 | 액션 | 색상 | 아이콘 |
|------|--------|------|------|------|
| 왼 → 오 | 작업/노트 | 완료 | #10B981 | ✅ |
| 오 → 왼 | 작업/노트 | 삭제 | #EF4444 | 🗑️ |
| 오 → 왼 | 이메일 | 보관 | #3B82F6 | 📦 |

**스와이프 임계값:** 80px

### 3. 풀 투 리프레시

| 상태 | 인디케이터 |
|------|-------------|
| 당기는 중 | "당겨서 새로고침" 텍스트 |
| 임계값 도달 | "새로고침" 텍스트 + 아이콘 회전 |
| 로딩 중 | 로딩 스피너 |
| 완료 | "새로고침 완료" 텍스트 |

### 4. 길게 누르기 (Long Press)

| 요소 | 동작 | 피드백 |
|------|------|--------|
| 리스트 아이템 | 선택 모드 진입 | 진동 (100ms), 배경색 변경 |
| 캘린더 이벤트 | 퀵 액션 메뉴 | 진동 (100ms), 메뉴 팝업 |
| 노트 카드 | 미리보기 모달 | 진동 (100ms), 모달 페이드 인 |

### 5. 애니메이션 지속 시간

| 유형 | 지속 시간 | 이징 |
|------|-----------|------|
| 페이드 인/아웃 | 200ms | ease-in-out |
| 슬라이드 | 300ms | cubic-bezier(0.4, 0.0, 0.2, 1) |
| 스케일 | 150ms | ease-out |
| 쉬머 | 1.5s | linear, 무한 반복 |
| 완료 체크 | 400ms | cubic-bezier(0.34, 1.56, 0.64, 1) (bounce) |

### 6. 키보드 처리

| 상황 | 동작 |
|------|------|
| 입력 필드 포커스 | 키보드 올라옴, 화면 스크롤 |
| 완료 키 | 다음 필드로 포커스 이동 (있는 경우) / 저장 (마지막 필드) |
| 백 키 | 키보드 내려감 (열려있는 경우) / 이전 화면 |
| ESC 키 (데스크톱) | 모달 닫기 / 검색 닫기 |
