## 1. 개요 (Overview)

### 1.1 문서 목적

본 문서는 TODO 앱의 기능, 회귀, 접근성, 성능 테스트 계획을 정의합니다. 소스 코드(`src/`)와 설계 문서(`docs/`)를 기반으로 테스트 범위와 기준을 명시합니다.

### 1.2 테스트 범위

| 카테고리 | 범위 |
|----------|------|
| **기능 테스트** | CRUD 연산, 필터링, 데이터 영속성, 다탭 동기화 |
| **회귀 테스트** | 기존 기능 변경 시 영향도 검증 |
| **접근성 테스트** | WCAG 2.1 AA 준수, 키보드 탐색, 스크린 리더 지원 |
| **성능 테스트** | 로드 시간, 렌더링 성능, localStorage I/O |

### 1.3 테스트 환경

| 항목 | 사양 |
|------|------|
| 브라우저 | Chrome 120+, Firefox 120+, Safari 17+, Edge 120+ |
| 디바이스 | 데스크톱 (1920x1080), 태블릿 (768x1024), 모바일 (375x667) |
| 스크린 리더 | NVDA (Windows), VoiceOver (macOS/iOS), JAWS (Windows) |
| 테스트 도구 | Jest, React Testing Library, Playwright/Vitest |

## 10. 결함 분류 및 관리 (Defect Classification & Management)

### 10.1 심각도 레벨

| 레벨 | 설명 | 예시 |
|------|------|------|
| **Critical (치명적)** | 앱 사용 불가능, 데이터 손실 | 태스크 추가 시 앱 크래시, 데이터 소실 |
| **Major (중요)** | 주요 기능 불가, 접근성 위반 | 체크박스 작동 안 함, 키보드 접근 불가 |
| **Minor (사소)** | 기능 제한적 작동, UI 오류 | 색상 대비비 미미하게 부족, 텍스트 오타 |
| **Trivial (미미)** | 영향 없음 | 불필요한 로그 출력 |

### 10.2 우선순위 레벨

| 레벨 | 설명 | 대응 시간 |
|------|------|----------|
| **P0** | 즉시 수정 필요 | 4시간 이내 |
| **P1** | 당일 수정 필요 | 24시간 이내 |
| **P2** | 이번 스프린트 내 수정 | 1주일 이내 |
| **P3** | 다음 버전에서 수정 | 다음 릴리스 |
