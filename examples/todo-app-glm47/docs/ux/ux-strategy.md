# UX 전략 문서
**작성일자:** 2026-03-02

---

## 1. 비전 및 목표

### 1.1 제품 비전
사용자가 자신의 삶을 자신 있게 계획하고, 기록하며, 목표를 달성할 수 있도록 돕는 **통합 생산성 플랫폼**

### 1.2 UX 목표
| 목표 | 성공 지표 |
|------|-----------|
| 직관적 학습 | 신규 사용자 5분 내 핵심 기능 완료 |
| 효율적 워크플로우 | 일반 작업 수행 클릭 수 3회 이하 |
| 감정적 안정감 | 사용자 불안감(어떻게 써야 할지 모름) 최소화 |
| 지속 가능한 습관 형성 | 30일 사용 유지율 40% 이상 |

## 2. 타겟 사용자 페르소나

### 페르소나 A: 체계적인 계획형 (Jun, 34세, 프로젝트 매니저)
- **목표:** 업무와 개인 일정을 체계적으로 관리하고 싶음
- **통증:** 여러 도구(캘린더, 메모, 투두) 간 데이터 분산
- **기대:** 빠른 입력과 명확한 시각화

### 페르소나 B: 유연한 아이디어형 (Soo, 27세, 디자이너)
- **목표:** 아이디어를 자유롭게 기록하고 연결하고 싶음
- **통증:** 계획보다 기록/탐색에 더 집중하고 싶으나 계획 도구가 너무 강제적임
- **기대:** 유연한 노트와 자연스러운 연결

### 페르소나 C: 습관 형성형 (Min, 22세, 대학생)
- **목표:** 공부/운동 같은 일상 습관을 지속적으로 유지하고 싶음
- **통증:** 계획 세우는 것은 쉬우나 지속하기 어려움
- **기대:** 작은 성취감을 주는 리마인더와 피드백

## 3. 사용자 여정 (User Journey)

### 3.1 신규 온보딩 여정

| 단계 | 사용자 행동 | 생각/감정 | 시스템 반응 | UX 목표 |
|------|-------------|-----------|------------|---------|
| 1. 랜딩 | 제품 접속 | "이게 뭐지?" | 명확한 가치 제안 + CTA | 호기심 유발 |
| 2. 가입 | 이메일/소셜 로그인 | "복잡하지 않았으면" | 최소 입력 필드, 30초 완료 | 진입 장벽 최소화 |
| 3. 빠른 설정 | 페르소나 선택/초기 플랜 템플릿 선택 | "내 스타일에 맞추고 싶어" | 3가지 스타일 질문, 추천 템플릿 | 맞춤형 시작 |
| 4. 첫 작업 | 첫 투두/이벤트 추가 | "뭐부터 해야 하지?" | 빈 상태 안내(Empty State) + 예시 | 자연스러운 시작 |
| 5. 첫 완료 | 작업 체크 | "이게 다인가?" | 감정적 피드백(애니메이션/메시지) | 긍정적 강화 |

### 3.2 일일 사용 여정 (Daily Rhythm)

| 시점 | 사용자 행동 | 생각/감정 | 시스템 반응 | UX 목표 |
|------|-------------|-----------|------------|---------|
| 아침 | 오늘 일정/투두 확인 | "오늘 뭐부터 하지?" | 대시보드 요약 + 우선순위 표시 | 빠른 파악 |
| 오전 | 새 작업 추가 및 스케줄링 | "언제 할 수 있지?" | 드래그 앤 드롭 + 빈 슬롯 제안 | 자연스러운 계획 |
| 오후 | 진행 상황 업데이트 | "얼마나 했지?" | 프로그레스 표시 + 동기 부여 메시지 | 지속 의지 강화 |
| 저녁 | 일간 리뷰 및 내일 계획 | "오늘은 뭐 했지?" | 자동 요약 + 내일 템플릿 제안 | 습관 형성 |
| 주간 | 주간 리뷰 및 목표 점검 | "이번 주 잘했어?" | 주간 인사이트 + 달성 시각화 | 성취감 제공 |

## 4. 핵심 플로우 (Core Flows)

### 4.1 투두(Todo) 생성 및 완료 플로우

```
[시작] → [퀵 액션 버튼 클릭] → [제목 입력] → [옵션 설정(마감일/태그/프로젝트)] → [저장] → [리스트 표시] → [완료 체크] → [완료 피드백] → [아카이브]
```

| 단계 | UI 요소 | 상호작용 | 예외 처리 |
|------|---------|----------|-----------|
| 퀵 액션 버튼 | 플로팅 버튼(FAB) 또는 인풋 바 | 클릭/포커스 | 권한 없음 → 알림 |
| 제목 입력 | 텍스트 필드 + 자동완성 | 입력 + Enter로 저장 | 빈 입력 → 유효성 검사 |
| 옵션 설정 | 드롭다운/모달 | 선택/드래그 | 취소 → 이전 상태 |
| 완료 체크 | 체크박스/왼쪽 스와이프 | 클릭/스와이프 | 완료 취소 → 복원 |

### 4.2 이벤트(Event) 스케줄링 플로우

```
[시작] → [캘린더 뷰에서 슬롯 선택] → [이벤트 생성 모달] → [제목/시간/반복 입력] → [참여자 추가] → [저장] → [캘린더 표시] → [알림]
```

| 단계 | UI 요소 | 상호작용 | 예외 처리 |
|------|---------|----------|-----------|
| 슬롯 선택 | 캘린더 그리드/타임라인 | 클릭/드래그 | 중복 → 충돌 표시 |
| 이벤트 생성 모달 | 폼 + 예약 시각화 | 입력/선택 | 필수 누락 → 인라인 에러 |
| 참여자 추가 | 멘션/이메일 입력 | 자동완성 + 초대 | 초대 실패 → 재시도 옵션 |

### 4.3 노트(Note) 생성 및 연결 플로우

```
[시작] → [노트 생성 버튼] → [에디터 진입] → [제목/내용 작성] → [태그/링크 추가] → [다른 노트/투두 연결] → [저장] → [노트 뷰] → [검색/백링크]
```

| 단계 | UI 요소 | 상호작용 | 예외 처리 |
|------|---------|----------|-----------|
| 에디터 진입 | 리치 텍스트 에디터 | 작성/포맷팅 | 자동 저장 주기적 |
| 연결 | @멘션 / ]링크 문법 | 자동완성 + 연결 표시 | 대상 없음 → 생성 제안 |

### 4.4 목표(Goal) 설정 및 진척 관리 플로우

```
[시작] → [목표 생성] → [목표 제목/기간 입력] → [마일스톤 추가] → [관련 투두/이벤트 연결] → [진척 업데이트] → [대시보드 시각화]
```

| 단계 | UI 요소 | 상호작용 | 예외 처리 |
|------|---------|----------|-----------|
| 목표 생성 | 목표 설정 모달 | 입력 + 마일스톤 추가 | 기간 미래 이후만 허용 |
| 진척 업데이트 | 프로그레스 바/슬라이더 | 드래그/클릭 | 0~100% 범위 제한 |

## 5. 정보구조 (Information Architecture)

### 5.1 사이트맵 (Site Map)

```
/
├── 대시보드 (Dashboard)
│   ├── 오늘 요약
│   ├── 주간 개요
│   └── 빠른 추가
├── 일정/캘린더 (Calendar)
│   ├── 월/주/일 뷰
│   ├── 이벤트 리스트
│   └── 반복 일정 관리
├── 작업 (Tasks)
│   ├── 인박스
│   ├── 프로젝트별
│   ├── 태그 필터
│   └── 완료/보관
├── 노트 (Notes)
│   ├── 모든 노트
│   ├── 노트북/폴더
│   ├── 백링크
│   └── 검색/필터
├── 목표 (Goals)
│   ├── 진행 중 목표
│   ├── 완료 목표
│   ├── 마일스톤
│   └── 인사이트
├── 설정 (Settings)
│   ├── 프로필
│   ├── 알림
│   ├── 통합
│   └── 데이터 내보내기/가져오기
└── 도움말 (Help)
    ├── 온보딩 재생
    ├── FAQ
    └── 피드백
```

### 5.2 내비게이션 구조

| 레벨 | 항목 | 설명 |
|------|------|------|
| L1 (주요 탭) | 대시보드, 일정, 작업, 노트, 목표 | 핵심 기능 영역 |
| L2 (서브 탭) | 각 영역 내 필터/뷰 | 뷰 전환 및 필터링 |
| L3 (컨텍스트) | 모달/사이드바 | 상세 작업 및 컨텍스트 정보 |
| L4 (설정/도움말) | 설정, 도움말 | 글로벌 옵션 및 지원 |

### 5.3 카테고리 및 태그 전략

| 엔티티 | 카테고리(계층형) | 태그(평면형) |
|--------|------------------|--------------|
| 작업 | 프로젝트/폴더 | 우선순위, 에너지, 상태 |
| 이벤트 | 캘린더, 위치 | 반복, 유형(회의/약속) |
| 노트 | 노트북/폴더 | 주제, 참조 |
| 목표 | 영역(업무/개인/건강) | 우선순위, 시기 |

### 5.4 검색 및 필터링 구조

```
검색
├── 전역 검색 (Command Palette)
│   ├── 텍스트 검색
│   ├── 필터 (엔티티 타입, 태그, 기간)
│   └── 자동완성
├── 개별 영역 필터
│   ├── 작업: 프로젝트, 태그, 마감일, 상태
│   ├── 이벤트: 캘린더, 반복, 참여자
│   ├── 노트: 노트북, 태그, 링크
│   └── 목표: 영역, 진척, 기간
└── 스마트 필터 (자동 생성)
    ├── 오늘/이번 주/이번 달
    ├── 긴급/중요 (Eisenhower)
    └── 관련 항목 (백링크 기반)
```

## 6. 상태 모델 (State Model)

### 6.1 작업(Task) 상태

| 상태 | 설명 | 전이 |
|------|------|------|
| Draft | 임시 저장 | → Inbox |
| Inbox | 수집 상태 | → Scheduled / Someday |
| Scheduled | 일정 지정됨 | → In Progress / Done |
| In Progress | 진행 중 | → Done / Paused |
| Paused | 일시 중단 | → In Progress / Archived |
| Done | 완료 | → Archived |
| Archived | 보관됨 | (복원 가능) |

### 6.2 이벤트(Event) 상태

| 상태 | 설명 |
|------|------|
| Upcoming | 아직 도래하지 않음 |
| Ongoing | 현재 진행 중 |
| Completed | 종료됨 |
| Cancelled | 취소됨 |

### 6.3 목표(Goal) 상태

| 상태 | 설명 |
|------|------|
| Planning | 계획 중 |
| Active | 진행 중 |
| On Hold | 일시 정지 |
| Completed | 달성됨 |
| Discontinued | 포기됨 |

## 7. UX 원칙

### 7.1 핵심 원칙
1. **직관성 (Intuitive):** 학습 곡선 최소화, 자연스러운 상호작용
2. **효율성 (Efficient):** 키보드 단축키, 빠른 입력, 자동 완성
3. **유연성 (Flexible):** 다양한 워크스타일 지원(GTD/Time Blocking)
4. **피드백 (Feedback):** 모든 상호작용에 명확한 시각/감각적 피드백
5. **접근성 (Accessible):** 키보드 네비게이션, 대비비율, 스크린 리더 지원

### 7.2 디자인 패턴
| 패턴 | 적용 범위 |
|------|-----------|
| 빈 상태 안내 (Empty State) | 빈 리스트, 첫 사용 시 |
| 점진적 공개 (Progressive Disclosure) | 복잡한 옵션/설정 |
| 드래그 앤 드롭 | 일정 재배치, 우선순위 조정 |
| 커맨드 팔레트 (Command Palette) | 전역 검색 및 빠른 명령 |
| 인라인 편집 | 제목/설명 바로 수정 |
| 컨텍스트 메뉴 | 우클릭/길게 누르기 옵션 |
