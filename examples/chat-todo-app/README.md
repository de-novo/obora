# Chat Todo App

브라우저에서 바로 실행 가능한 기능이 풍부한 Todo 애플리케이션입니다.

## 기능

- **추가**: 입력창에 텍스트를 입력하고 '추가' 버튼 또는 Enter 키로 추가
- **완료 토글**: 체크박스를 클릭하여 완료/미완료 상태 변경
- **편집**: 항목을 더블클릭하거나 편집 버튼(✎)을 클릭하여 텍스트 수정 (Enter 저장, Esc 취소)
- **삭제**: 삭제 버튼(×)으로 항목 제거
- **필터**: 전체 / 진행중 / 완료 탭으로 필터링
- **완료 항목 정리**: 완료된 항목 모두 삭제
- **남은 개수 표시**: 진행중인 항목 수 표시
- **localStorage 저장**: 브라우저 저장소에 자동 저장
- **접근성**: ARIA 라벨, 역할(role), 키보드 네비게이션 지원
- **키보드 친화적**: Tab 키로 이동, Enter/Esc로 편집 제어

## 실행 방법

### 방법 1: npm 사용 (권장)

```bash
cd examples/chat-todo-app
npm start
```

브라우저에서 `http://localhost:8080`으로 접속하세요.

### 방법 2: 직접 열기

`index.html` 파일을 브라우저에서 직접 열어도 사용할 수 있습니다.

## 기술 스택

- HTML5
- CSS3 (변수, 반응형 디자인)
- Vanilla JavaScript (의존성 없음)
- Node.js 내장 HTTP 서버
- localStorage API
