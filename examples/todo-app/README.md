# Todo App — Built with Obora

AI Control Runtime으로 투두앱을 기획부터 구현까지 자동 생성하는 예제.

## 워크플로우 흐름
1. 📋 기획 (Product Manager) → 요구사항/사용자 스토리
2. 🏗️ 설계 (Architect) → 컴포넌트/데이터 모델
3. 🤝 설계 합의 (3 Reviewers) → Majority vote
4. 🎨 UI 디자인 (Designer) → 스타일/인터랙션 스펙
5. 💻 구현 (Developer) → React + TypeScript 코드
6. 👀 코드 리뷰 (2 Reviewers) → Peer review
7. 📝 최종 요약 (Product Manager)

## 실행
```bash
cd examples/todo-app
obora run workflow.yaml
```
