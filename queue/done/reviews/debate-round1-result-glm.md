## 기각된 이슈

### @tool 데코레이터의 this 바인딩 오류
- **기각 이유**: 스펙에 명시된 의도적인 설계 제약입니다. `decorators.ts:31-33`에 "Decorated tools must be stateless (no this-dependent logic)" 주석으로 명시되어 있으며, 스펙 코드와 동일한 방식으로 구현되었습니다. 데코레이터는 클래스 정의 시점에 실행되므로 인스턴스 바인딩을 미리 할 수 없는 TypeScript 데코레이터의 구조적 한계입니다. 사용 예제도 모두 stateless 메서드로 제시되어 있어 이는 기능 결함이 아닌 설계 의도입니다. 인스턴스 의존 도구가 필요한 경우 스펙에서 제공하는 `Tool` 인터페이스를 직접 구현하는 방식을 사용해야 합니다.
