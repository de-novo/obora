# Architecture Docs

This directory is the repo-local home for durable Obora architecture notes.

The previous `docs/architecture` path was a symlink to a local Obsidian vault
path outside this repository. That target is not available in a clean checkout,
so architecture material that is required for maintenance or release decisions
must be tracked directly in this repository.
