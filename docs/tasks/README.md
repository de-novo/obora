## 상태 정의

| 상태 | 설명 |
|------|------|
| `TODO` | 대기 중 |
| `IN_PROGRESS` | 진행 중 |
| `BLOCKED` | 차단됨 |
| `REVIEW` | 리뷰 대기 |
| `DONE` | 완료 |

## 우선순위 정의

| 우선순위 | 설명 |
|----------|------|
| `P0` | 긴급 (즉시) |
| `P1` | 높음 (이번 주) |
| `P2` | 보통 (이번 스프린트) |
| `P3` | 낮음 (백로그) |

## 네이밍 규칙

TASK-{번호}-{제목}.md
