# Getting Started

5분 안에 Obora를 실행해보세요.

## Prerequisites

- Node.js 20+
- npm 또는 pnpm

## Quick Start

```bash
npm install -g @obora/cli
obora init my-project
cd my-project
obora run
```

샘플 워크플로우 실행:

```bash
obora run --workflow examples/hello-obora.yaml
```
