# Specification Docs

This directory is the repo-local home for durable Obora specification notes.

The previous `docs/spec` path was a symlink to a local Obsidian vault path outside
this repository. That target is not available in a clean checkout, so release
and documentation audits cannot treat it as source-of-truth material.

Use this directory for specifications that must travel with the repository.
Drafts may still start elsewhere, but promoted specs should land here as normal
tracked Markdown files.

Current specification anchors:

- [Current Capabilities](../current-capabilities.md)
- [Support Scope](../support-scope.md)
- [Testing Policy](../testing-policy.md)
- [Release Readiness](../release-readiness.md)
